# NtLineの仮閉塞とデバッグ表示

`NtLineGraph.asset` に8つの仮閉塞を定義した。距離は各エッジが参照する Geometry 上の距離（m）。

| 閉塞 | 範囲 |
| --- | --- |
| NT-B01 | 直線 0～500 m |
| NT-B02 | 直線 500～1000 m |
| NT-B03 | 緩和曲線 1000～1250 m と曲線 1250～1650 m |
| NT-B04 | 緩和曲線 1650～1900 m |
| NT-B05・B06 | 直進側 1900～2400 m・2400～3000 m |
| NT-B07・B08 | 分岐側 1900～2400 m・2400～3000 m |

`NtLine` シーンの `Debug/TrackCircuits` に `TrackCircuitDebugDisplay` を配置している。Sceneビューでは Gizmos を有効にすると閉塞の線とIDが見える。編集時は黄色、再生時は占有が赤、空きが緑。Gameビューでは同じ色の線と右上の状態一覧を表示する。コンポーネントの `Show In Scene View`・`Show In Game View` で表示を切り替えられる。

再生中の状態は `TrackCircuitSimulationController` から読み、列車のエッジ占有範囲を反映する。列車位置を取得できない場合や回路の定義が不正な場合、軌道回路シミュレーションは安全側として全区間を占有にする。境界上に列車がいる場合は両側の区間を占有とみなす。

Graph の閉塞範囲を編集した後は、コンポーネントのコンテキストメニュー `Rebuild Circuit Debug Display` で線を作り直す。この段階では閉塞の区分と占有表示までで、信号現示や進路制御による列車の進入制限はまだ接続していない。
