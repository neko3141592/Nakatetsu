# 中田留置線の実寸線形案

[全体図](中田留置線線形図.drawio) · [有効長・分岐器の詳細図](中田留置線詳細図.drawio) · [参照した配線図](../../../../References/中田鉄道配線図.drawio)

200m編成12本を電留1〜12番に初期配置する。電留1・2番は駅着発線の延長で、現行の回路名は電留1・2T。車庫側は本線に近い順に電留3〜12番とし、両端接続の2線が3・4番、旧引上線が5番、車止め付きの7線が6〜12番。

距離 `s` は現行の `NT01_baseline` の連続距離。現行Geometryの終端17,320mから同じ方位・高さで直線を延長する。横位置 `x` は終端を向いて右を正とし、2番線を0m、3番線を+4mとする。平面の曲線は新設する車庫の線路だけに置き、縦断は現行の中田終端側と同じ0‰。

## 分岐器の位置と番数

新設分岐器には31〜44の仮番号を振った。すべてR172.854mの分岐円弧、低速入換25km/h以下の案。R172.854mの円弧と直線が接するモデルで、仮軌間1,067mmの軌間線が交わる角度は約6.360°。クロッシング角を θ として N = 1/(2 tan(θ/2)) が9になるよう、分岐円弧の半径を R = 2 × 1.067 × 9² = 172.854m に設定した。実製品の番数・レール形状は別途確定する。 [運輸安全委員会の分岐器番数の説明](https://jtsb.mlit.go.jp/railway/rep-acci/RA2022-5-1.pdf)
