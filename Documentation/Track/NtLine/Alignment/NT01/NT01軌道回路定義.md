# NT01 中鉄中央 軌道回路定義

[NT01配線図](../../Wiring/Stations/NT01配線図.drawio)の8回路を、[線形定義](NT01線形定義.md)のs座標に合わせて[NakatetsuGraph.asset](../../../../../Assets/Nakatetsu/Track/Network/Data/NakatetsuGraph.asset)の`circuits`へ設定した。sは2番線車止め基準のGeometry距離で、曲線・渡り線の走行実距離ではない。

## 境界の決め方

- 1RT終端は入力済みのs=310mを維持し、2RTも同じ位置で23Tへ切り替える。ホーム終端s=260mより50m先までがホーム回路となる。23Tには1番線の合流曲線・斜め直線と2番線側を含める。
- 23Tと21イTは、23接続点s=444.79166mと21イs=520mの中間s=482.39583mで分ける。
- 3RTと22イTは、Cubic終端s=480mと22イs=520mの中間s=500mで分ける。
- シーサスの直進側は、イ・ロ接続点の中間s=556.45835mで分ける。2番線側は21イT／22ロT、3番線側は22イT／21ロTとなる。
- 斜め経路は21イT／21ロT、22イT／22ロTに含める。境界は交差中心からNT02側へ2mずらしたs=558.45835mに置く。独立した21-22Tは作らない。
- 駅間側の2線は現状のGraph終端s=650mまで、それぞれ22ロT・21ロTに含める。駅間の線形追加時に、駅間回路との境界を定義する。

これはゲーム用の占有区間定義。絶縁継目・支障限界など実設備の配置は別途決める。既存のEdge・Node・線形・距離LUTは変更せず、回路境界は`TrackCircuitSection`の開始・終了位置で表す。

占有判定は既存の`TrackCircuitSimulationLogic`を使う。定義した18区間で全10 Edgeを隙間なく覆い、共有境界以外の重複はない。列車の占有範囲が境界に一致した場合は、既存の判定仕様により両側の回路を占有とする。斜め2経路は別Edgeのままで、交差点に乗り移り接続を設けない。

Unity 6000.4.0f1の検証用プロジェクトで保存済みAssetを読み込み、既存の線形・経路検証14件と軌道回路・ID検証6件、計20件が成功した。全区間の占有、全境界をまたぐ占有、空線路、不正入力、転轍機3方向の所属とID参照を確認した。シーンへの配置・Controllerの接続は今回の変更に含めない。
