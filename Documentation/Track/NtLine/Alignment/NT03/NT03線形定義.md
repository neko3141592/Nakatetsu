# NT03 新桜町 線形提案

両端式2面2線の寸法案。[線形図](NT03線形図.drawio)で形を編集し、この資料で数値を管理する。Unity Assetへの反映は別工程。

## 座標とホーム

図上部の数直線は、NT01車止めを始点`s=0`とするNT線共通Geometry `NT01_baseline`からの連続距離`s`（m）を示す。NT03の対象範囲は`s=2040〜2440m`、ホーム中央は`s=2240m`、ホーム範囲は`s=2120〜2360m`。下記のホーム中央基準`u`とは`s=u+2240`で変換する。駅境界・拡大図の左端でも距離を0に戻さない。各線路の走行実距離・営業キロとは区別する。今回の案では既存キロ程表から基準線の駅中心距離を仮定し、駅間の線形定義で接続・勾配を確定する。

駅内の基準線距離を`u`、横オフセットを`x`とする。`u=0`はホーム中央、正方向は古谷方面、`x`はその方向を向いて右が正。駅構内の基準線は直線、縦断は0‰、カント0、レール面Y=0とする。

配置検討用の全線距離`S`は、NT01車止めを0、NT01ホーム中央を140mとして`S=140+1000×営業キロ+u`と置く。NT03は営業キロ2.1km、中心`S=2240m`、対象範囲`u=-200〜200m`（`S=2040〜2440m`）。`S`は今回の案では連続Geometry距離`s`と同じ値。駅間の基準線の接続・勾配は別工程で確定する。`S`を全線のUnity Z座標とは扱わない。

全ホームは`u=−120〜+120m`、長さ240m、レール面から高さ1.1m。基準編成は20m×10両。下り列車の車体前端は`u=+100m`、上りは`u=−100m`、停止中の車体範囲は共通で`u=−100〜+100m`。先頭20m車の中心は下り`+90m`、上り`−90m`。ホーム両端に20mの余裕を取る。

Unity向けIDはアンダースコア区切り、Geometryは駅ごとに新設せず、NT01から続く`NT01_baseline`を延長する。配線図のイ／ロはUnityではA／Bとする。軌道回路境界・制限速度・連動進路はこの線形案とは別に定義する。

## 横配置・区間

| 項目 | x範囲・位置 (m) |
| --- | ---: |
| 1番線（下り） | −2 |
| 2番線（上り） | +2 |
| 1番線ホーム | −9.7〜−3.7（幅6m） |
| 2番線ホーム | +3.7〜+9.7（幅6m） |

両線とも対象範囲の全長を一定オフセットとする。前後の駅間との線路中心間隔は4m、Cubic・分岐器は不要。ホーム縁と線路中心の距離は1.7mのゲーム用配置値。

## 次の定義工程

駅間の線形と接続点を確定した後、`NakatetsuGraph`内の共通Geometry `NT01_baseline`を延長し、Node・Edge・Connectionを追加する。ホームの範囲と軌道回路の範囲は一致させる必要はなく、回路境界と支障限界は別工程で決める。
