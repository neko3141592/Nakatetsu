# NT04 千海 線形提案

島式1面2線の寸法案。[線形図](NT04線形図.drawio)と[配線図](../../Wiring/Stations/NT04配線図.drawio)で確認する。2026-10-13改訂。ホーム210m・駅回路220mとし、ホーム両端が拡幅・縮幅曲線に沿ってすぼむ形へ変更した。短縮した線形・駅回路・前後駅間の回路境界をGraph・ATC Assetへ反映した。ホーム210m・回路220mは共通Geometry距離s上の寸法で、曲線の走行実距離とは区別する。ホームと両端を絞る縁は設計寸法として管理し、ホームMesh・Prefab・シーン配置は作成していない。

## 座標とホーム

NT01車止めを`s=0`とする共通Geometry `NT01_baseline`の連続距離を使う。ホーム中央は`s=3340m`、補助座標は`s=u+3340`。横位置`x`は線路群中央を0とし、s増加方向を向いて右が正。営業キロ・走行実距離・Unity全線Z座標とは区別する。

| 項目 | 連続距離s (m) | 中央基準u (m) |
| --- | --- | --- |
| 拡幅を含む構内線形 | 3140〜3540 | −200〜+200 |
| ホーム | 3235〜3445 | −105〜+105 |
| 1・2番線の駅回路 | 3230〜3450 | −110〜+110 |
| 停止中の車体（20m×10両） | 3240〜3440 | −100〜+100 |
| 下り / 上りの車体前端 | 3440 / 3240 | +100 / −100 |
| 下り / 上りの先頭車中心 | 3430 / 3250 | +90 / −90 |

ホーム長210m、高さ1.1m。200m編成からホーム端まで各5m、ホーム端から回路境界までさらに各5m。構内線形の両端3140／3540mは220m回路の境界ではない。

Cubicは`x=x0+(x1−x0)(3t²−2t³)`、`t=(s−s0)/(s1−s0)`。両端で横勾配0となり、駅間の線間4mと中央の線間10mを接線連続でつなぐ。旧案の640m（3020〜3660m）から400mへ240m短縮した。ホーム始端3235mから3290m、3390mからホーム終端3445mの各55mに曲線が重なる。分岐器は設けない。

## 両端を絞ったホーム縁

片側線路の絶対横位置を`a(s)=abs(x_track(s))`、横位置勾配を`p(s)=dx_track/ds`とし、ホーム片側の縁を`b(s)=a(s)−1.7√(1+p(s)²)`、島式ホームを`x=−b(s)〜+b(s)`とする。1.7mは局所接線に対する離れのゲーム用設計値。一定線間部は幅6.600m、両ホーム端は線路位置`±4.085778m`・勾配絶対値`0.027866667`で、ホーム幅4.770236mとなる。図のホームはこの式の計算点による編集可能なベクトル形状。

図は横配置検討用に直線・0‰・カント0の基準線で描く。Graphでは既存の共通Geometryの実曲線を維持し、横オフセットだけを3140〜3540mの短縮形へ変更した。基準線は3371〜3471mがR−550緩和曲線で、その先は円弧。ホーム後半の3371〜3445m（74m）はこの基準線曲線にも重なる。幅4.770〜6.600mと縁の式は基準線に対する局所横配置の設計値であり、実曲線に沿うホームMeshの建築限界はMesh作成時に確認する。

## 前後の回路と接続

駅回路は`NT04_DT`・`NT04_UT`の3230〜3450m（共通Geometry距離220m）。Unityの再生成済み距離表による走行実距離は下り219.90503m、上り220.41876m。配線上の表示名は1RT・2LT。[全線区間一覧](../../Wiring/軌道回路区間一覧.md)を距離とIDの正本とする。前駅側の4Tは2880〜3230m、次駅側の1Tは3450〜3700mとし、拡幅曲線のうち駅回路の外側も隣接駅間回路で覆う。

NT05の線形始端3700mまで、構内線形終端3540mから160mの一定線間を残す（旧40m）。共通Geometry上の横オフセットは図の`x+2m`へ変換する。駅ごとの独立Geometryは作らない。
