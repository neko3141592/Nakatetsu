# NT05 東長野 線形提案

島式2面4線。待避線のホームへの戻しを緩和曲線付きに変更し、ホーム縁を曲線に沿わせた案。[線形図](NT05線形図.drawio)は構内全体とホーム幅の拡大図の2ページ。この線路形状は中鉄全体の`NakatetsuGraph`へ反映済み。[Unity反映記録](../NT01_NT05Unity反映.md)に区間・ID・確認結果を記載する。

## 座標とホーム

上部の数直線はNT01車止めを0mとする共通Geometry距離`s`（m）。駅内の補助座標`u`とは`s=u+4040`で変換する。駅や拡大図の始点で0に戻さない。営業キロ・Edgeの走行実距離とは区別する。

NT05ホーム中央は`s=4040m`、構内範囲は`s=3700〜4380m`。ホームは`s=3920〜4160m`、長さ240m、レール面から高さ1.1m。20m×10両の車体範囲を`s=3940〜4140m`として両端に20mの余裕を取る。駅中心距離は既存キロ程表から置いた提案値で、駅間は今回、直線・0‰で接続した。

図内の横座標`x`は複線中央を0、古谷方面を向いて右が正。共通GeometryをNT01の2番線基準で延長するときの横オフセットは`x+2m`に変換する。基準線は駅内で直線、縦断0‰、カント0、レール面Y=0。

## ホーム幅の保証

本線側のホーム縁は線路中心から1.700m離した直線、待避線側のホーム縁は線路中心から横方向に`c=1.705913043m`離した曲線とする。最大接線角αに対して`c=1.7/cosα`とし、待避線の接線傾きが`|dx/ds|≤tanα`なので、線路中心からホーム縁への平面最短距離は1.7m以上になる。

各横断面の線路中心間隔を`d(s)`とすると、Geometryに直角な横断面で測るホーム幅は次のとおり。

```text
W(s) = d(s) − 1.700 − c
ホーム内のd(s)：8.600〜11.400m
W(s)：5.194086957〜7.994086957m
```

ホーム端から中央の直線部へ向かって待避線が単調に外側へ移り、反対端は前後対称。最小幅は両端、最大幅は中央部である。したがって点検用サンプル間も含め、全区間で幅5m以上・8m以下となる。図の本線側縁は直線なので、両縁間の平面最短距離も最小横断幅を下回らない。上下2面は左右対称で同じ幅。

## 緩和曲線の実装と計算式

[TrackEdgeTransitionInOffsetSegment](../../../../../Assets/Nakatetsu/Track/Graph/Edge/Scripts/TrackEdgeTransitionInOffsetSegment.cs)・[TrackEdgeTransitionOutOffsetSegment](../../../../../Assets/Nakatetsu/Track/Graph/Edge/Scripts/TrackEdgeTransitionOutOffsetSegment.cs)を使用する。共通の[計算実装](../../../../../Assets/Nakatetsu/Track/Graph/Edge/Scripts/TrackEdgeTransitionOffsetSegment.cs)で、Geometry距離に対して曲率を線形に変える。実距離をパラメーターとする厳密なクロソイドとは区別する。

区間内Geometry距離z、区間長L、符号付き半径R、開始接線角θ₀、q=sinθとする。直線Geometry上では`dq/dz`が平面曲率となる。

```text
緩和入口：q(z) = sinθ₀ + z² / (2RL)
緩和出口：q(z) = sinθ₀ + (z − z²/(2L)) / R
横オフセットの傾き：dx/dz = q / sqrt(1−q²)
横オフセット：x(z) = x₀ + ∫[0→z] q(v)/sqrt(1−q(v)²) dv
入口の曲率：z/(RL)         0 → 1/R
出口の曲率：(1−z/L)/R      1/R → 0
```

位置は適応Simpson積分、傾き・曲率は上の式で評価する。曲がった共通Geometryへ適用する際の最終的なEdge曲率は基準線形状も含むため、この平面曲率と区別する。図・表は直線基準線に対する計算値。無効な長さ・半径・区間外入力・接線が90°に達する定義は無効値として返す。

ホームMeshの生成・シーンへの配置・新しい軌道回路の設定は今回の更新には含めない。保存後のGraph Assetでも、左右の待避線のホーム幅5〜8m・前後対称性・戻し曲線の位置／接線／曲率の連続性を確認した。
