# NT06 山田橋 線形定義

2026-10-27に相対式2面2線へ変更。ホームに合わせた線路の拡幅・縮幅をなくし、前後の本線と同じ線路間隔4mとする。[線形図](NT06線形図.drawio)・[配線図](../../Wiring/Stations/NT06配線図.drawio)を参照。JSON・Unity Graph・ATCへ反映する。ホームは設計寸法で、Mesh・Prefab・シーン配置は未作成。

## 座標とホーム

共通Geometry `NT01_baseline`の距離sを使う。駅内の対象範囲は4920〜5560m、駅中心は5240m。基準線自体の曲線・勾配は維持し、ホーム用の横オフセット変化だけを取り除く。ホーム区間は平面線形上の直線内にあり、レール面高さはY=-9.248125m、勾配0‰（[縦断線形](../縦断線形.md)）。

| 項目 | 定義 |
| --- | --- |
| 1番線・下り | `NT06_track1`、Unity offset=0mで一定 |
| 2番線・上り | `NT06_track2`、Unity offset=4mで一定 |
| 線路間隔 | 4m |
| ホーム形式 | 相対式2面2線。線路の外側に各1面 |
| ホーム範囲 | s=5135〜5345m（210m） |
| 各ホーム幅 | 3.3m（従来の島式幅6.6mを左右へ分ける設計値） |
| ホーム高さ | レール面から1.1m |
| ホーム縁 | 線路中心から外側へ1.7m |
| 駅回路 | `NT06_DT`・`NT06_UT`、s=5130〜5350m（220m） |

図上の横座標xはUnity offsetから2mを引いた値。線路中心はx=-2m／+2m、下りホームはx=-7〜-3.7m、上りホームはx=+3.7〜+7mとする。分岐器は置かない。

20m×10両の200m車体はs=5140〜5340mに収め、車体からホーム端まで各5m、ホーム端から駅回路境界まで各5mの余裕を維持する。前後駅間との接続、Edge ID、回路ID・境界は変えない。駅回路を外れた構内Edgeは従来どおり前後の駅間回路に含める。
