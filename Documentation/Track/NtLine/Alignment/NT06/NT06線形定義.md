# NT06 山田橋 線形提案

島式1面2線の寸法案。[線形図](NT06線形図.drawio)で形を編集し、この資料で数値を管理する。2026-10-12に線路と軌道回路を共通の`NakatetsuGraph`へ反映した。

## 座標とホーム

図上部の数直線は、NT01車止めを始点`s=0`とするNT線共通Geometry `NT01_baseline`からの連続距離`s`（m）を示す。NT06の対象範囲は`s=4920〜5560m`、ホーム中央は`s=5240m`、ホーム範囲は`s=5120〜5360m`。下記のホーム中央基準`u`とは`s=u+5240`で変換する。駅境界・拡大図の左端でも距離を0に戻さない。各線路の走行実距離・営業キロとは区別する。今回の案では既存キロ程表から基準線の駅中心距離を仮定し、駅間の線形定義で接続・勾配を確定する。

駅内の基準線距離を`u`、横オフセットを`x`とする。`u=0`はホーム中央、正方向は古谷方面、`x`はその方向を向いて右が正。図は直線の基準線上で横配置を示す。現在のUnity Assetでは既存の共通Geometryを維持し、`s=4920〜4998m`はR550緩和曲線出口、その先は直線になる。ホーム区間`s=5120〜5360m`は直線内に収まる。縦断は0‰、カント0、レール面Y=0とする。

配置検討用の全線距離`S`は、NT01車止めを0、NT01ホーム中央を140mとして`S=140+1000×営業キロ+u`と置く。NT06は営業キロ5.1km、中心`S=5240m`、対象範囲`u=-320〜320m`（`S=4920〜5560m`）。`S`は今回の案では連続Geometry距離`s`と同じ値。駅間の基準線の接続・勾配は別工程で確定する。`S`を全線のUnity Z座標とは扱わない。

全ホームは`u=−120〜+120m`、長さ240m、レール面から高さ1.1m。基準編成は20m×10両。下り列車の車体前端は`u=+100m`、上りは`u=−100m`、停止中の車体範囲は共通で`u=−100〜+100m`。先頭20m車の中心は下り`+90m`、上り`−90m`。ホーム両端に20mの余裕を取る。

Unity向けIDはアンダースコア区切り、Geometryは駅ごとに新設せず、NT01から続く`NT01_baseline`を使う。配線図のイ／ロはUnityではA／Bとする。軌道回路・制限速度の反映内容は末尾に記す。

Cubicは`x=x0+(x1−x0)(3t²−2t³)`、`t=(u−u0)/(u1−u0)`。拡幅・縮幅の長さ180m、片線の横移動3m。両端で横勾配0とし、前後区間の位置・接線を合わせる。ホームは直線区間内に収まり、両端に20mの直線を残す。分岐器は置かない。
