## 線形と回路

- 共通Geometry `NT01_baseline` の5598〜7900mを直線で延長し、縦断0‰を維持した。図の横座標xはUnityのオフセットへx+2mで変換する。
- NT06〜NT07の5560〜6120mを、上下各3回路・各186.666667mに分けた。線間4mから5mへの調整はCubicで行う。
- NT07ホームは6520〜6760m、ホーム回路は6470〜6790m。電留1・2Tは7000〜7280m。
- 古谷側4線の外部回路は7020〜7900m。7500〜7900mは指定どおり各線1区間の既存Cubicを使い、緩行線x=±9.5mから±6m、急行線x=±14.5mから±10mへ戻した。
- 構内26回路、NT06〜NT07駅間6回路、古谷側4回路の計36回路で、新しい39 Edgeを79区間に分けて隙間なく覆った。境界とIDの一覧は[軌道回路定義](NT07軌道回路定義.md)を参照する。
- 古谷側の番号は現在の配線図に合わせ、根元を27／30、斜め途中を26A／31Aとした。根元の定位は電留直進、斜め途中の定位は緩行線側。線形図の両ページの番号・定位3本線も合わせた。

旧線形の2区間のTransitionは、端点の位置・傾きを保持する `TrackEdgeCubicHermiteOffsetSegment` を追加して3次放物線の形状を再現した。古谷側7500〜7900mの線間戻しは、この型ではなく既存の単純な `TrackEdgeCubicOffsetSegment` を使う。

## 連動とATC

進路IDはExcelのIDに `NT07_` を付ける。連動図表の発点・着点、鎖錠、進路鎖錠、接近鎖錠回路と解錠時間を設定した。

| 種類 | 進路IDの駅接頭辞を除いた部分 |
| --- | --- |
| 下り第1場内 | 101RA、101RB |
| 下り第2場内 | 201R、202R、203R、204R |
| 下り出発 | 205RE、205RL、206RE、206RL |
| 上り場内 | 207LE、207LL、208LE、208LL |
| 上り出発 | 203L、204L |
| 入換 | 301RA、301RB、302RA、302RB、303LA、303LB、304LA、304LB |

21・22・25・26・28・29・31・32はA／Bの2動てことして同一の鎖錠位置を要求する。23・24・27・30は単独。転轍機の轍査鎖錠は、Excelの各てこの回路を対応する物理Connectionへ設定した。回路の共有または転轍機要求位置の相違がある進路には、相互に競合進路を設定した。

連動Assetの `memberTrackCircuitIds` は入力として読む31回路。構内26回路と、第1場内の接近回路 `NT06_NT07_D3T`、古谷側4外部回路を含む。構内26回路はInterlocking制御、駅間・古谷側はBlock制御。新しい回路の速度設定は120km/h。作業中に更新された全線の最高運転速度105km/hと既存NT01の回路速度40km/hは保持して再コンパイルした。

第2場内信号機は後方21B／22Bの先、6291.200029mの回路境界とした。連動の発点は21BT／22BTのまま、ATC進路はその先の24T／23Tから開始する。第2場内に後方21／22の鎖錠条件を追加していない。すべての過走防護設定は無効・転轍機要求なし・時間0秒。

## 必要になった処理の修正

| ファイル | 修正と理由 |
| --- | --- |
| `TrackEdgeCompiler.cs` | 6180〜6206.200195mなどで、最後の短い積分区間がfloatへの丸めで記録済み端点と重複していた。最後の端点が既にある場合だけ重複を除く。表せない中間刻みは従来どおり失敗する |
| `TrackAtcPathLogic.cs` | 第1場内終端から、物理的につながった設定済み・開通済みの第2場内進路へ接続する。未設定・取消済み・未開通・逆方向・非接続の進路には進まない |
| `TrackAtcValidationLogic.cs` | 24進路で使わない渡り線分岐にもCompilerが設定した通常方向を認める。静的進路から方向が得られない区間に限定し、不正・未指定方向は失敗する。進路なしの区間は両方向の停止扱いで、通常方向だけでは進入・継続を許可しない |
