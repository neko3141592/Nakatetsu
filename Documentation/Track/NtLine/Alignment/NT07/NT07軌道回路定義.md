# NT07 小泉公園 軌道回路定義

[NT07配線図](../../Wiring/Stations/NT07配線図.drawio)と[線形定義](NT07線形定義.md)に対応する、[NakatetsuGraph.asset](../../../../../Assets/Nakatetsu/Track/Network/Data/NakatetsuGraph.asset)の回路・Edge区間。対象はNT06構内端5560mから古谷側7900mまでと、電留1・2線の7280m終端まで。sはNT01車止めを0mとする共通Geometry `NT01_baseline` の連続距離で、走行実距離・営業キロとは区別する。

## 回路と区間

構内は26回路（ホーム4・転轍機20・電留2）。論理IDの区切りはアンダースコア、配線図のイ・ロはUnity上で `A`・`B` とする。1つの転轍機回路に直進側・分岐側・共通側の複数Edge区間を含める。根元の転轍機は27／30、斜め経路途中の転轍機は26イ／31イとして、現在の配線図に合わせる。

## 境界の決め方

- 入口21／22のシーサスは、6180mと6282.400058mの中央6231.200029mでイ側・ロ側を分ける。斜め経路も各転轍機回路へまとめ、交差点に接続点や独立回路を設けない。
- 21ロT・22ロTは、転轍機を通過した後の6291.200029mまで含める。23／24接続点6300mとの間の中央が、第2場内信号機と23T／24Tの開始境界になる。
- ホーム4回路は6470〜6790m。ホーム範囲6520〜6760mを含み、前側50m・後側30mを確保する。
- ホーム古谷側の27T／30Tと28イT／29イTは、根元6820mと電留線側6850mの中央6835mで分ける。斜め経路の27T／30Tと26イT／31イTは、6820mと6878.948993mの中央6849.474497mで分ける。
- 古谷側の分岐間は、接続点の中央を境界とする。急行線の25イT／26ロTと32イT／31ロTは6917.672147m、斜め急行経路の26イT／26ロTと31イT／31ロTは6920.636284m、斜め緩行経路の26イT／25ロTと31イT／32ロTは6927.184885m。外側から緩行線への渡り線は6924.220748mで分ける。
- 電留線間の28／29シーサスは、6850mと6947.398744mの中央6898.699372mで分ける。電留1T・電留2Tの開始は7000m、車止め側の終端は7280m。
- 古谷側は7020mで転轍機回路から4線の外部回路へ切り替える。7500〜7900mのCubicで、急行線はx=±14.5mから±10m、緩行線はx=±9.5mから±6mへ戻す。

表の表示は小数点以下6桁まで。Assetに保存する単精度値の丸め差が生じる場合は、接続点・共有境界で同じ値を共用する。定義上は全39 Edgeを79区間で隙間なく覆い、共有境界以外の重複はない。列車が共有境界に一致した場合は既存の占有判定に従って両側回路を占有とする。

## 第1・第2場内の接続

連動図表の第2場内進路は、発点の22ロT／21ロTを保持する。ATCの進路区間は信号位置6291.200029mから、22ロT発は23T、21ロT発は24Tで開始する。21ロT／22ロTには通過済みの転轍機を含めて占有・轍査鎖錠を行い、第2場内進路に後方の21／22の鎖錠条件を追加しない。

第1場内の終端と第2場内の始端はこの共有境界で接続する。第2場内進路が成立している場合に、その進路へATCを引き継ぐ。過走防護回路・過走防護進路は今回定義しない。
