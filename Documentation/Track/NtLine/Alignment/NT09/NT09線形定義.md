# NT09 秋杉 線形定義

内側緩行線の島式1面2線と、外側の急行通過2線。[線形図](NT09線形図.drawio)・[配線図](../../Wiring/Stations/NT09配線図.drawio)を参照。2026-11-01に古谷方の縮幅・再拡幅を撤去し、古谷から広い線間を維持する形へ改訂した。猿沼方のCubic縮幅は維持する。ホームMesh・Prefabは未作成。

## 座標と範囲

距離sはNT01車止めからの共通Geometry `NT01_baseline`上の距離。横位置xは線路群中央を0mとし、s増加方向を向いた右が正。Unityの横オフセットはx+2m。営業キロ・Edge走行実距離・UnityワールドZとは区別する。

| 項目 | s範囲・位置 (m) |
| --- | --- |
| 駅Edge・駅回路 | 8730〜8950 |
| ホーム | 8735〜8945・長さ210m |
| ホーム中央 | 8840 |
| 停車車体 | 8740〜8940・長さ200m |

縦断は[縦断線形](../縦断線形.md)を維持し、ホーム区間は0‰。今回の変更は横オフセットのみで、駅・回路・分岐器の接続関係や共通Geometryの勾配は変更しない。

## 古谷から広い線間を維持する

| 線路 | 古谷〜ホーム中央のx (m) | Unity横オフセット (m) | 猿沼方縮幅後のx (m) |
| --- | ---: | ---: | ---: |
| 下り急行線 | -10 | -8 | -6 |
| 下り緩行線 | -6 | -4 | -2 |
| 上り緩行線 | +6 | +8 | +2 |
| 上り急行線 | +10 | +12 | +6 |

古谷出口からホーム中央以遠のs=8885mまで4線の横位置を一定にする。同一sでの急緩間の横間隔は4m、上下緩行線間は12m。旧s=8200〜8400mの縮幅とs=8550〜8795mの再拡幅は撤去した。

| 開始s (m) | 終了s (m) | 形状 |
| ---: | ---: | --- |
| 8150 | 8730 | Constant・古谷出口から秋杉入口 |
| 8730 | 8885 | Constant・ホーム中央以遠まで |
| 8885 | 9130 | Cubic・縮幅 |

ホームの中鉄中央方と中央部を平行直線とし、最後の60mだけ猿沼方の縮幅曲線に重ねる。猿沼方のCubicは`t=(s-a)/(b-a)`、`f(t)=3t²−2t³`で両端の傾きを0にする。駅Edge境界が曲線途中にある部分は、同じCubicを`CubicHermite`へ切り出し、位置と傾きを保つ。境界ごとに傾き0のCubicへ置き換えない。

## ホーム形状

ホーム縁は緩行線中心から中央側へ横方向1.7mとし、猿沼方の端だけを絞る。幅は中央8.600m、中鉄中央方端8.600m、猿沼方端7.396m。ホーム面はレール面から1.1m、車体200mに対する端の余裕は共通距離sで各5m。曲線上の走行実距離とは区別する。

古谷〜秋杉は広い4線配置のままつなぐ。秋杉〜東福岡の駅間は従来どおりs=9130〜9550mを集約した4線配置とする。

今回の変更は古谷〜秋杉の4 Edgeと秋杉構内の4 Edgeが対象。駅・回路境界、接続関係、猿沼方縮幅の位置・接線を維持し、Unity Graphの距離表とCompiled ATCを再生成済み。古谷構内を含む12 Edgeを1m刻みで評価し、一定区間の横位置・傾きと、猿沼方の駅間への位置・接線の連続性をUnity側で確認した。全線119 Edge・154回路・58進路は維持する。

## 駅回路220m（2026-10-13反映）

ホームは`s=8735〜8945m`（210m）、駅回路は`s=8730〜8950m`（220m）。200m車体からホーム端まで各5m、ホーム端から回路境界まで各5mとする。図の線形対象範囲`8730〜8950m`は駅Edgeと回路の共通区間。

| 回路ID | 配線上の表示 | 開始s (m) | 終了s (m) | 基準線上の長さ (m) |
| --- | --- | ---: | ---: | ---: |
| `NT09_1RT` | 1RT | 8730 | 8950 | 220 |
| `NT09_2RT` | 2RT | 8730 | 8950 | 220 |
| `NT09_3LT` | 3LT | 8730 | 8950 | 220 |
| `NT09_4LT` | 4LT | 8730 | 8950 | 220 |

駅Edgeの両端を駅回路の両端に一致させ、各駅Edgeを1つの220m駅回路で覆う。旧対象範囲の外側区間は前後の駅間Edgeへ移し、駅間回路はその駅間Edge内で連続させる。ホーム端は駅Edge端・回路境界の5m内側。NT04・NT06は拡幅線形を保持する例外とし、駅Edgeと回路の境界を分ける。[全線区間一覧](../../Wiring/軌道回路区間一覧.md)と[全線図](../../Wiring/軌道回路区間一覧.drawio)に、全回路の名前・境界・Edge上の内訳をまとめる。Graph・ATCへ反映済み。実ID・保存距離・検証結果は[NT08〜NT11反映記録](../NT08_NT11Unity反映.md)を参照。
