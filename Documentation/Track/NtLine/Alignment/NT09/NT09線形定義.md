# NT09 秋杉 線形定義

内側緩行線の島式1面2線と、外側の急行通過2線。[線形図](NT09線形図.drawio)・[配線図](../../Wiring/Stations/NT09配線図.drawio)を参照。2026-10-26に急緩一体のCubic拡幅へ改訂し、JSON・Unity Graph・ATCへ反映した。ホームMesh・Prefabは未作成。

## 座標と範囲

距離sはNT01車止めからの共通Geometry `NT01_baseline`上の距離。横位置xは線路群中央を0mとし、s増加方向を向いた右が正。Unityの横オフセットはx+2m。営業キロ・Edge走行実距離・UnityワールドZとは区別する。

| 項目 | s範囲・位置 (m) |
| --- | --- |
| 駅Edge・駅回路 | 8730〜8950 |
| ホーム | 8735〜8945・長さ210m |
| ホーム中央 | 8840 |
| 停車車体 | 8740〜8940・長さ200m |

縦断は[縦断線形](../縦断線形.md)を維持し、ホーム区間は0‰。今回の変更は横オフセットのみで、駅・回路・分岐器の接続関係や共通Geometryの勾配は変更しない。

## 急行線・緩行線を一緒に広げる

| 線路 | 駅間のx (m) | 最大拡幅時のx (m) |
| --- | ---: | ---: |
| 下り急行線 | -6 | -10 |
| 下り緩行線 | -2 | -6 |
| 上り緩行線 | +2 | +6 |
| 上り急行線 | +6 | +10 |

下りの2線を同量だけ左へ、上りの2線を同量だけ右へ動かす。同一sでの急緩間の横間隔は4mのまま、上下緩行線間を駅間4mからホーム中央12mへ広げる。

| 開始s (m) | 終了s (m) | 形状 |
| ---: | ---: | --- |
| 8550 | 8795 | Cubic・拡幅 |
| 8795 | 8885 | Constant・ホーム中央 |
| 8885 | 9130 | Cubic・縮幅 |

ホームの最初と最後の60mを拡幅・縮幅曲線に重ね、中央90mを平行直線とする。Cubicは`t=(s-a)/(b-a)`、`f(t)=3t²−2t³`で両端の傾きを0にする。駅Edge境界が曲線途中にある部分は、同じCubicを`CubicHermite`へ切り出し、位置と傾きを保つ。境界ごとに傾き0のCubicへ置き換えない。

## ホーム形状

ホーム縁は緩行線中心から中央側へ横方向1.7mとし、線路に沿って両端を絞る。幅は中央8.600m、中鉄中央方端7.396m、猿沼方端7.396m。ホーム面はレール面から1.1m、車体200mに対する端の余裕は共通距離sで各5m。曲線上の走行実距離とは区別する。

古谷出口ではs=8200〜8400mで線間を詰め、8400〜8550mを集約したまま秋杉へつなぐ。秋杉〜東福岡の駅間はs=9130〜9550mを集約した4線配置とする。

Graphの20 Edgeを1m刻みに評価し、Cubicの形状、区間・Edge境界での位置と接線の連続性をUnity側で検証した。119 Edgeの距離表と58進路のCompiled ATCを再生成済み。回路IDを維持した。

## 駅回路220m（2026-10-13反映）

ホームは`s=8735〜8945m`（210m）、駅回路は`s=8730〜8950m`（220m）。200m車体からホーム端まで各5m、ホーム端から回路境界まで各5mとする。図の線形対象範囲`8730〜8950m`は駅Edgeと回路の共通区間。

| 回路ID | 配線上の表示 | 開始s (m) | 終了s (m) | 基準線上の長さ (m) |
| --- | --- | ---: | ---: | ---: |
| `NT09_1RT` | 1RT | 8730 | 8950 | 220 |
| `NT09_2RT` | 2RT | 8730 | 8950 | 220 |
| `NT09_3LT` | 3LT | 8730 | 8950 | 220 |
| `NT09_4LT` | 4LT | 8730 | 8950 | 220 |

駅Edgeの両端を駅回路の両端に一致させ、各駅Edgeを1つの220m駅回路で覆う。旧対象範囲の外側区間は前後の駅間Edgeへ移し、駅間回路はその駅間Edge内で連続させる。ホーム端は駅Edge端・回路境界の5m内側。NT04・NT06は拡幅線形を保持する例外とし、駅Edgeと回路の境界を分ける。[全線区間一覧](../../Wiring/軌道回路区間一覧.md)と[全線図](../../Wiring/軌道回路区間一覧.drawio)に、全回路の名前・境界・Edge上の内訳をまとめる。Graph・ATCへ反映済み。実ID・保存距離・検証結果は[NT08〜NT11反映記録](../NT08_NT11Unity反映.md)を参照。
