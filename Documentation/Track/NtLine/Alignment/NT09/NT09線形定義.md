# NT09 秋杉 線形定義

4線区間の内側緩行線に島式1面2線を置く寸法案。[線形図](NT09線形図.drawio)と[配線図](../../Wiring/Stations/NT09配線図.drawio)を対応させる。2026-10-13に資料を作成した。線形・回路をGraph・ATCへ反映済み。ホームMesh・Prefab・ホームのシーン配置は未作成。

駅名・営業キロは[Stations.xlsx](../../../../References/Stations.xlsx)の`キロ程表!B11:E11`（NT09、秋杉、8.7km）、配線構成は[中田鉄道配線図](../../../../References/中田鉄道配線図.drawio)を参照する。ホーム長・幅・線形はゲーム用の提案値。

2026-10-13改訂：分岐器のない駅としてホーム210m・駅回路220mへ統一した。駅Edge＝駅回路220mをGraph・ATCへ反映した。ホーム210mは資料上の寸法で、Graphにホーム項目はない。

## 座標とホーム

数直線はNT01車止めを0mとする共通Geometry `NT01_baseline`の連続距離`s`（m）。駅中心は`140+1000×営業キロ`から`s=8840m`と仮置きする。対象範囲は`s=8730〜8950m`、ホーム中央基準`u`との変換は`s=u+8840`。図の左端や駅境界で距離を0へ戻さない。営業キロ・各線路の走行実距離・Unityの全線Z座標とは区別する。

横座標`x`は線路群の中央を0mとし、営業キロが増える方向を向いて右が正。図ではその方向を右向き、`x`の正方向を下向きに描く。距離方向約6.364px/m・横方向18px/mの縮尺で、横配置を距離方向の約2.83倍に拡大する。1線・2番線・3番線・4線は線路群をこの順で整理するための図内番号。外側の1・4線はホームのない通過線、内側の2・3番線はホーム番線とする。

ホーム長210m・幅8.6m、レール面から高さ1.1m。基準編成は20m×10両で、両端に5mずつの余裕を取る。ホーム範囲と軌道回路範囲は別に管理する。保存済み回路の区間は下記を参照。

## 前後との接続とUnity反映

[NT08 古谷](../NT08/NT08線形定義.md)の駅Edge終端8150mから本駅Edge始端8730mまで580mを4線駅間Edgeとする。ホーム端8735／8945mは駅Edge端8730／8950mの各5m内側。[NT10 東福岡](../NT10/NT10線形定義.md)の駅Edge始端9730mまでは8950〜9730mの780mを4線駅間Edgeとし、同じ横位置でGraphへ接続済み。

独立した駅Geometryを新設せず、共通Geometry `NT01_baseline`を延長した。図の`x`からGeometry局所右方向へのオフセットへは`x+2m`で変換し、前後の接続点でも同じ位置・接線を保つ。

回路境界は下表のとおりGraph・ATCへ保存した。駅・駅間はBlock制御、追加回路の速度設定は120km/h、既存の路線最高速度105km/hを踏襲する。前後の位置・接線と全回路被覆を保存・再読込で検証済み。ホームMesh・Prefab・ホームのシーン配置は未作成。

## 駅回路220m（2026-10-13反映）

ホームは`s=8735〜8945m`（210m）、駅回路は`s=8730〜8950m`（220m）。200m車体からホーム端まで各5m、ホーム端から回路境界まで各5mとする。図の線形対象範囲`8730〜8950m`は駅Edgeと回路の共通区間。
