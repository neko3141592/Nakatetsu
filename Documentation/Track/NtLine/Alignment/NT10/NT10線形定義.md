# NT10 東福岡 線形定義

[中田鉄道配線図](../../../../References/中田鉄道配線図.drawio)の連続4線・中央島式ホームを、[Stations.xlsx](../../../../References/Stations.xlsx)の営業キロ9.7kmに合わせて寸法化した計画資料。[線形図](NT10線形図.drawio)と[配線図](../../Wiring/Stations/NT10配線図.drawio)を対にして管理する。2026-10-13作成。線形・回路をGraph・ATCへ反映済み。ホームMesh・Prefab・ホームのシーン配置は未作成。

2026-10-13改訂：分岐器のない駅としてホーム210m・駅回路220mへ統一した。駅Edge＝駅回路220mをGraph・ATCへ反映した。ホーム210mは資料寸法で、Graphにホーム項目はない。

## 座標と範囲

図上部の数直線は、NT01車止めを`s=0`とする共通Geometry `NT01_baseline`からの連続距離`s`（m）。ホーム中央は`s=9840m`、対象範囲は`s=9730〜9950m`、ホームは`s=9735〜9945m`とする。駅境界・図の左端でも距離を0に戻さない。ホーム中央を原点とする補助座標`u`とは`s=u+9840`で変換する。

駅中心は、既存の配置検討と同じく`140+1000×営業キロ`で仮定した。NT10は`140+9700=9840m`。この数値は営業キロ・各線路の走行実距離・Unityの全線Z座標とは区別し、共通Geometryは11860mまで直線・0‰で延長し、前後接続を検証済み。

`u`の正方向はNT11猿沼方面（営業キロが増える方向）、横位置`x`はその方向を向いて右を正とする。図では`s`の増加を右、`x`の増加を下に描く。距離方向は約6.364px/m、横位置方向は18px/mで、横位置を約2.83倍に拡大している。駅内の基準線は直線、縦断は0‰、カント0、レール面Y=0の提案とする。

## 横配置

NT09秋杉方からNT11猿沼方まで4線を連続させ、緩行線だけが中央の島式ホームに面する。外側急行線にはホーム・分岐器を置かない。外側の「1線／4線」と内側の「2番線／3番線」は今回の整理用の線番号で、ホームを持つ番線と通過線を区別する。

| 対象 | 横位置・範囲x (m) | 用途 |
| --- | ---: | --- |
| 1線 | −10 | 下り急行・通過線、ホームなし |
| 2番線 | −6 | 下り緩行・ホーム停車 |
| 3番線 | +6 | 上り緩行・ホーム停車 |
| 4線 | +10 | 上り急行・通過線、ホームなし |
| 島式ホーム | −4.3〜+4.3 | 2・3番線用、幅8.6m |

同方向の急行・緩行線の中心間隔は4m、上下緩行線の中心間隔は12m。ホーム縁から2・3番線の線路中心まではそれぞれ1.7mのゲーム用配置値とし、`12−1.7×2=8.6m`のホーム幅を取る。

4線とも駅Edge範囲220mを同じ横位置で通す。駅内の線間拡大・縮小、Cubicによる寄せ、渡り線は設けない。NT09からの駅間Edgeは8950〜9730m、NT11への駅間Edgeは9950〜10140m。同じ横位置で接続し、各駅間回路を駅間Edge内で区切ってGraph・ATCへ保存した。

## ホームと停止位置

島式1面2線のホームは長さ210m、幅8.6m、レール面から高さ1.1m。基準編成は20m×10両の200mで、ホーム中央に収め、両端に5mずつ余裕を取る。

| 項目 | 連続距離s (m) | 中央基準u (m) |
| --- | ---: | ---: |
| 計画対象範囲 | 9730〜9950 | −110〜+110 |
| ホーム | 9735〜9945 | −105〜+105 |
| ホーム中央 | 9840 | 0 |
| 停止中の車体範囲 | 9740〜9940 | −100〜+100 |
| 2番線・下りの車体前端 | 9940 | +100 |
| 3番線・上りの車体前端 | 9740 | −100 |
| 下り先頭20m車の中心 | 9930 | +90 |
| 上り先頭20m車の中心 | 9750 | −90 |

ホーム端と車体端の余裕は`9740−9735=5m`、`9945−9940=5m`。図中の車体範囲は線路中心線と別の破線で示し、ホーム全長210mとの違いを確認できるようにしている。

## 駅回路220m（2026-10-13反映）

ホームは`s=9735〜9945m`（210m）、駅回路は`s=9730〜9950m`（220m）。200m車体からホーム端まで各5m、ホーム端から回路境界まで各5mとする。図の線形対象範囲`9730〜9950m`は駅Edgeと回路の共通区間。

| 回路ID | 配線上の表示 | 開始s (m) | 終了s (m) | 基準線上の長さ (m) |
| --- | --- | ---: | ---: | ---: |
| `NT10_1RT` | 1RT | 9730 | 9950 | 220 |
| `NT10_2RT` | 2RT | 9730 | 9950 | 220 |
| `NT10_3LT` | 3LT | 9730 | 9950 | 220 |
| `NT10_4LT` | 4LT | 9730 | 9950 | 220 |

駅Edgeの両端を駅回路の両端に一致させ、各駅Edgeを1つの220m駅回路で覆う。旧対象範囲の外側区間は前後の駅間Edgeへ移し、駅間回路はその駅間Edge内で連続させる。ホーム端は駅Edge端・回路境界の5m内側。NT04・NT06は拡幅線形を保持する例外とし、駅Edgeと回路の境界を分ける。[全線区間一覧](../../Wiring/軌道回路区間一覧.md)と[全線図](../../Wiring/軌道回路区間一覧.drawio)に、全回路の名前・境界・Edge上の内訳をまとめる。Graph・ATCへ反映済み。実ID・保存距離・検証結果は[NT08〜NT11反映記録](../NT08_NT11Unity反映.md)を参照。
