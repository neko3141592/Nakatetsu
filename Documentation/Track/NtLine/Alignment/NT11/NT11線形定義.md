## 座標と対象範囲

図上部の数直線はNT01車止めを`s=0`とする共通Geometry `NT01_baseline`からの連続距離`s`（m）。駅中心は既存の配置検討と同じく`140+1000×営業キロ`と仮定し、NT11では`s=10740m`とする。対象範囲は`s=10140〜11860m`、ホームは`s=10620〜10860m`。ホーム中央を原点とする補助座標`u`とは`s=u+10740`で変換する。図の左端・ページ切替・駅境界でも距離を0に戻さない。

営業キロ、共通Geometryの距離`s`、各線路の走行実距離、Unityの全線Z座標は別の量。Cubicや渡り線では、基準線の距離差より走行実距離がわずかに長くなる。

`s`の正方向はNT10東福岡方から猿沼終端方、横位置`x`はその方向を向いて右を正とする。図では`s`が右、`x`が下へ増える。全体図は距離方向1.5px/m・横方向24px/m、終端詳細図は距離方向2.6px/m・横方向24px/m。横位置はそれぞれ距離方向の16倍・約9.23倍に拡大している。曲線は計算点を結ぶ編集可能な折れ線で表現し、図の見た目から半径を読まない。

基準線を既存7900m終端から11860mまで直線で延長してGraphへ保存した。駅内は縦断0‰・カント0・レール面Y=0m。以下の曲線表・図形は理論設計値、回路の区間表はNative保存値を示す。単精度の丸めにより入口共通境界は理論10227.127487mから保存値10227.1279296875m、26連絡部始端は理論11020.012484mから保存値11020.0126953125mとなる。

## 入口の同方向急緩シーサス

入口には下り1・2番線間の21／22と、上り3・4番線間の23／24を置く。番号・イ／ロの対応は今回の配線図に合わせた提案。分岐器の定位は各番線の直進側とし、同じ番号のイ／ロは一組の2動てことして整理する。

各斜線は同じ寸法で、`s=10180m`から`s=10274.254973m`まで、横移動4m。`R=400m`の円弧、走行実距離50mの直線、逆向きの`R=400m`円弧を連続させる。各円弧の転角は`α=3.176658686°`。円弧・直線・逆円弧の接線は連続し、前後主線と同じ向きに戻る。

| 渡り線 | イ：開始s / x (m) | ロ：終了s / x (m) | 接続先 |
| --- | --- | --- | --- |
| 21 | 10180 / −10 | 10274.254973 / −6 | 下り1→2 |
| 22 | 10180 / −6 | 10274.254973 / −10 | 下り2→1 |
| 23 | 10180 / +6 | 10274.254973 / +10 | 上り3→4 |
| 24 | 10180 / +10 | 10274.254973 / +6 | 上り4→3 |

| 要素 | 基準線方向の投影長 (m) | 走行実距離 (m) |
| --- | ---: | ---: |
| 第1円弧 R400 | 22.165901119 | 22.177261313 |
| 対角直線 | 49.923171103 | 50.000000000 |
| 第2逆円弧 R400 | 22.165901119 | 22.177261313 |
| 合計 | 94.254973340 | 94.354522626 |

横移動の確認式は`2R(1−cosα)+50sinα=4m`、基準線方向長は`2Rsinα+50cosα=94.254973340m`。図では円弧を計算点の折れ線として描く。

21／22の交差は`s=10227.127487m, x=−8m`、23／24の交差は同じ`s`で`x=+8m`。交差部に接続点を設けず、一方の斜線から他方へ進む経路を作らない。保存済み回路では、NT07の保存済み定義と同じく主線・各斜線の回路境界をこの共通距離sに揃える。回路を同じ距離で区切っても交差部を線路接続にはしない。NT11連動の18進路・11転轍機鎖錠を保存し、入口の直進・渡りを検証済み。

## 終端の25・中央両開き26と3つの車止め

渡り線25は2番線の`25イ: s=10900m, x=−6m`から、1番線の`25ロ: s=11080m, x=−16m`へ向かう。基準線距離180mのCubicで両端の接線を直線にそろえる。25イ定位は2番線から26側の対称Arc連絡部へ、反位は25ロから急行1へ向かう経路とする。25ロの主線側は1番線直進を定位とする。

26は`s=11160m, x=0m`で、中央の電留・緩行引上3を共通端とする左右対称の両開き分岐。2・3番線の対称Arc連絡部と中央引上の3枝から構成する。定位は3番線ホーム側、反位は2番線ホーム側とし、定位側も曲線で通す。

| 26の状態 | 許す接続 | 備考 |
| --- | --- | --- |
| 定位 | 3番線ホーム側 ↔ 東側緩行引上3 | 3番線側曲線・定位 |
| 反位 | 2番線ホーム側のArc連絡部 ↔ 東側緩行引上3 | 2番線側曲線・反位 |

26の西側同士、すなわち2番線ホーム側と3番線ホーム側を直接結ぶ経路はない。2番線から3番線へ折り返す場合は、26反位で引上3へ入り、26を定位に切り替えて3番線へ戻す接続構造となる。26の定位・反位を含む入換進路をNT11連動へ反映し、2番線→電留→3番線の折返しを保存・再読込後に検証済み。

中央x=0mの緩行引上3は`s=11160〜11400m`の240m。200m編成を`s=11190〜11390m`に収め、電留回路の両端に各10m、26合流点から車体後端まで30m、車体前端から車止めまで10mの寸法余裕を取る。この余裕は車止め保護距離や分岐器の支障限界を保証する値ではなく、ゲーム用の配置提案。

| 尾端 | 車止めs (m) | x (m) | 接続 |
| --- | ---: | ---: | --- |
| 急行引上1 | 11860 | −6 | 1番線から連続、25を介して2番線からも進入 |
| 緩行引上3 | 11400 | 0 | 26定位で3番線、反位で2番線から進入 |
| 急行引上4 | 11860 | +6 | 4番線から連続 |

車止めは合計3箇所。2番線専用の第4車止めは設けない。緩行引上3の車止め`s=11400m`は、4番線が`x=+6m`へ到達する`s=11640m`より240m手前。3の尾端はx=0m、4の尾端はx=+6mとなり、距離・横位置とも離れた独立した線路で接続しない。

## 26の10番・左右対称Arcの寸法案

[JP5773780B2の式1](https://patents.google.com/patent/JP5773780B2/ja#description)の両開きを基準とする全分岐角をβと表記し、`β=2atan(1/(2n))`、片側角を`θ=β/2`とする。n=10では片側θ=2.862405226°、全角β=5.724810452°。R400mはゲーム用の提案値であり、10番の規格半径を示すものではない。

片側の横移動6mを、駅側Arcの0.499064449m、斜直線の5.001871102m、26側逆Arcの0.499064449mに分ける。各Arcの基準線方向投影長は19.975046778m、斜直線は投影100.037422046m・走行実距離100.162390766m。連絡部全体は基準線方向139.987515601m・走行実距離140.129107344m。2番線の横位置を反転したものが3番線の経路で、端点・接線は鏡映関係を保つ。駅側Arcは既存平行線への接続調整、26側Arcは両開き分岐曲線として区別する。
