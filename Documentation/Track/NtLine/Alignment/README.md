## 距離の統一

全図の上部の数直線は、NT01車止めを0mとするNT線共通Geometryからの連続距離`s`（m）で統一する。駅ごとに0へ戻さず、拡大図も全体図と同じ距離を表示する。共通Geometry `NT01_baseline`の既存0〜5598mを保ち、NT07追加時に5598〜7900mの直線を継ぎ足す。NT06構内終端5560m以降にNT07への駅間と構内・古谷側4線をつなぐ。駅ごとの独立Geometryは作らない。各図の横配置を共通Geometryの局所右方向へのオフセットとして反映するため、基準線の曲線区間では線路もその曲線に沿う。縦断は0‰を維持する。

NT05〜NT06の駅間は4380〜4920mの540mで、上下とも180mずつの3軌道回路とする。境界は4380／4560／4740／4920m。IDは`NT05_NT06_D1T`〜`D3T`、`NT05_NT06_U1T`〜`U3T`で、東長野から遠ざかる順に番号を付ける。東長野の上り場内進路の接近鎖錠「上り1T」は`NT05_NT06_U1T`に対応する。

NT06〜NT07の駅間は5560〜6120mの560mで、上下とも186.666667mずつの3軌道回路とする。境界は5560／5746.666667／5933.333333／6120m。IDは`NT06_NT07_D1T`〜`D3T`、`NT06_NT07_U1T`〜`U3T`で、NT06から遠ざかる順に番号を付ける。小泉公園の第1場内進路の接近鎖錠「下り1T」は、NT07に最も近い`NT06_NT07_D3T`に対応する。

各線路の走行実距離・営業キロとは区別する。駅中心距離は既存キロ程表から`140+1000×営業キロ`と仮定した提案値。NT02〜NT07の区間表で使うホーム中央基準`u`は補助座標で、次の式でGeometry距離へ変換する。

| 駅 | Geometry距離sの範囲 (m) | ホーム中央s (m) | uからの変換 |
| --- | --- | ---: | --- |
| NT01 | 0〜650 | 140 | 車止め基準sをそのまま使う |
| NT02 | 1140〜1540 | 1340 | s=u+1340 |
| NT03 | 2040〜2440 | 2240 | s=u+2240 |
| NT04 | 3020〜3660 | 3340 | s=u+3340 |
| NT05 | 3700〜4380 | 4040 | s=u+4040 |
| NT06 | 4920〜5560 | 5240 | s=u+5240 |
| NT07 | 6120〜7320 | 6640 | s=u+6640 |

各駅のu=0はホーム中央。Geometry距離sは全駅共通のNT01車止め基準とする。駅内のx=0は複線の中央で、NT01の2番線中心基準とは2mずれる。NT01出口のx=0／4mは駅間基準ではx=−2／+2mに対応する。共通GeometryをNT01の2番線基準で延長する場合、NT02〜NT07の図の横座標xからUnityの横オフセットへはx+2mで変換する。これは横座標系の違いであり、線路を横に移動させるものではない。

全線配置検討用Sは今回の案では共通Geometry距離sと同じ値で、駅中心を営業キロ×1000+140mに置く。以下は構内範囲同士の間隔で、駅間の曲線・勾配・軌道回路長を確定した表ではない。

| 駅・区間 | 駅中心S (m) | 構内範囲S (m) | 次駅構内までの残り (m) |
| --- | ---: | --- | ---: |
| NT01 | 140 | 0〜650 | 490 |
| NT02 | 1340 | 1140〜1540 | 500 |
| NT03 | 2240 | 2040〜2440 | 580 |
| NT04 | 3340 | 3020〜3660 | 40 |
| NT05 | 4040 | 3700〜4380 | 540 |
| NT06 | 5240 | 4920〜5560 | 560 |
| NT07 | 6640 | 6120〜7320 | 600（NT08ホーム始端案まで。線間戻しは7500〜7900m） |

NT04〜NT05は中心間700mに対し構内範囲の間に40mを残す。NT07の配線計画上の古谷側出口S=7320mから、更新後のNT08営業キロ7.9kmに対応する中心S=8040mへ240mホームを仮置きした始端S=7920mまでは600m。今回の線路定義はこの駅間の7900mまでを含む。7500〜7900mは4線を各1区間のCubicで寄せ、緩行線x=±6m・急行線x=±10mに戻す。NT08のホーム・構内配線はまだ定義していない。

## NT07の古谷側

旧TD-ATCのNT07に合わせ、斜め経路の途中から緩行線へ分岐する構造にした。番号と定位・反位は現在の配線図・連動図表にそろえる。下り2番線は27反位から26イへ進み、26イ定位で緩行線、26イ反位で26ロ経由の急行線へ進む。27定位は電留1線への直進。上り側は30・31イ・31ロが対応し、30定位は電留2線への直進。1・4番線から緩行へ向かう25イ／ロ・32イ／ロは別の渡り線。旧の内側±2.5m・外側±14.5m・緩行±9.5mと曲線パラメータを採用し、240mホームを直線内に収めた。

旧Transitionの3次放物線は、端点オフセットと端点の傾きを指定する`TrackEdgeCubicHermiteOffsetSegment`で保持する。古谷側7500〜7900mの線間戻しには、両端の傾きが0の既存`TrackEdgeCubicOffsetSegment`を使う。[NT07定義](NT07/NT07線形定義.md)に距離の変換・位置・経路を記す。

今回追加する範囲は39 Edge・36軌道回路・NT07の24進路（場内・出発16、入換8）。既存分と合わせた定義は75 Edge・88軌道回路・ATC進路38本（NT01の6・NT05の8・NT07の24）となる。過走防護は定義しない。Assetのみを作成し、NtLineシーンへの連動装置の追加・登録は別工程とする。

## 編集する順番

各駅のdraw.io図で線形とホームの見え方を確認し、対応する線形定義の区間表で数値を編集する。NT07は全体図と古谷側拡大図の2ページ。線路・軌道回路は共通Graph、連動進路は駅ごとのInterlocking Assetへ反映する。NT07のAsset検証・反映後は、シーンへの接続とNT08以降の定義へ進む。
