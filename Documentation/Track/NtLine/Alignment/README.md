# NT線 線形定義

NT02〜NT11の駅構内定義。ホーム形式は指定内容、駅名・中心間距離は[既存のキロ程表](../../../References/Stations.xlsx)を使う。寸法はゲーム用の設計値。線路・軌道回路はNT11まで`NakatetsuGraph`へ反映済み。初回の[NT01〜NT05反映記録](NT01_NT05Unity反映.md)、[NT06定義](NT06/NT06線形定義.md)、[NT07初回反映記録](NT07/NT07Unity反映.md)は各工程の履歴。[NT08〜NT11反映記録](NT08_NT11Unity反映.md)に最新の119 Edge・154回路・56進路と、NT11連動・NtLine.unity登録の変更をまとめる。NT07電留1・2線は7280m、古谷方4線は7930mまで。ホームMesh・Prefab・ホームのシーン配置は未作成。

## 距離の統一

全図の上部の数直線は、NT01車止めを0mとするNT線共通Geometryからの連続距離`s`（m）で統一する。駅ごとに0へ戻さず、拡大図も全体図と同じ距離を表示する。共通Geometry `NT01_baseline`の既存0〜5598mを保ち、NT07追加時に5598〜7900m、NT08〜NT11追加時に7900〜11860mの直線を継ぎ足した。NT06構内終端5560m以降にNT07への駅間と構内・古谷側4線をつなぐ。駅ごとの独立Geometryは作らない。各図の横配置を共通Geometryの局所右方向へのオフセットとして反映するため、基準線の曲線区間では線路もその曲線に沿う。縦断は0‰を維持する。

保存済みAssetのNT05〜NT06駅間Edgeは4380〜4920m。NT06の220m回路始端5130mまで駅間回路を伸ばしてGraph・ATCへ反映し、境界を4380／4560／4740／5130mとする（3TがNT06構内Edgeにもまたがる）。IDは`NT05_NT06_D1T`〜`D3T`、`NT05_NT06_U1T`〜`U3T`で、東長野から遠ざかる順に番号を付ける。東長野の上り場内進路の接近鎖錠「上り1T」は`NT05_NT06_U1T`に対応する。

保存済みAssetのNT06〜NT07駅間Edgeは5560〜6120m。NT06の220m回路終端5350mから駅間回路を始める形をGraph・ATCへ反映し、境界を5350／5746.666500／5933.333500／6120mとする（1TがNT06構内Edgeにもまたがる）。IDは`NT06_NT07_D1T`〜`D3T`、`NT06_NT07_U1T`〜`U3T`で、NT06から遠ざかる順に番号を付ける。小泉公園の第1場内進路の接近鎖錠「下り1T」は、NT07に最も近い`NT06_NT07_D3T`に対応する。

各線路の走行実距離・営業キロとは区別する。駅中心距離は既存キロ程表から`140+1000×営業キロ`と仮定した提案値。NT02〜NT07の区間表で使うホーム中央基準`u`は補助座標で、次の式でGeometry距離へ変換する。

| --- | --- | ---: | --- |
| NT01 | 0〜650 | 140 | 車止め基準sをそのまま使う |
| NT02 | 1230〜1450 | 1340 | s=u+1340 |
| NT03 | 2130〜2350 | 2240 | s=u+2240 |
| NT04 | 3140〜3540 | 3340 | s=u+3340 |
| NT05 | 3700〜4380 | 4040 | s=u+4040 |
| NT06 | 4920〜5560 | 5240 | s=u+5240 |
| NT07 | 6120〜7320 | 6640 | s=u+6640 |
| NT08 | 7930〜8150 | 8040 | s=u+8040 |
| NT09 | 8730〜8950 | 8840 | s=u+8840 |
| NT10 | 9730〜9950 | 9840 | s=u+9840 |

各駅のu=0はホーム中央。Geometry距離sは全駅共通のNT01車止め基準とする。駅内のx=0は複線の中央で、NT01の2番線中心基準とは2mずれる。NT01出口のx=0／4mは駅間基準ではx=−2／+2mに対応する。共通GeometryをNT01の2番線基準で延長する場合、NT02〜NT11の図の横座標xからUnityの横オフセットへはx+2mで変換する。これは横座標系の違いであり、線路を横に移動させるものではない。

全線配置検討用Sは今回の案では共通Geometry距離sと同じ値で、駅中心を営業キロ×1000+140mに置く。以下は構内範囲同士の間隔で、駅間の曲線・勾配・軌道回路長を確定した表ではない。

## NT08〜NT11の現行線形

配線は現在の[中田鉄道配線図](../../../References/中田鉄道配線図.drawio)、駅名・キロ程は正本Excelの2026-10-13保存値を使う。古谷7.9km、秋杉8.7km、東福岡9.7km、猿沼10.6kmで、ホーム中央sは営業キロ×1000+140m。旧の配線略図より、現在のマスターにある猿沼の終端3線を優先する。

NT08〜NT10は内側の上下緩行線だけに島式ホームを置く。線順は下り急行1線・下り緩行2番線・上り緩行3番線・上り急行4線、横位置x=−10／−6／+6／+10mで一定。ホームはx=−4.3〜+4.3m、長さ210m・幅8.6m。番号は今回の図面整理用で、1・4はホームのない通過線として表記する。

NT11は入口の同方向急緩シーサスと方向別2面の240mホームを設ける。ホーム部の外側1・4番線はx=±16m、内側2・3番線はx=±6mで、各ホーム幅6.6mを取る。ホーム後の25は2番線から1番線への渡り線。その先では2・3番線を左右対称のArc＋斜直線＋逆Arcで中央x=0mへ寄せ、s=11160mの両開き26へ合流する。26は10番案、片側角2.862405226°・全角5.724810452°とし、R400mはゲーム用提案。定位は3番線側の曲線、反位は2番線側の曲線とし、2・3番線ホーム同士を直接接続しない。中央の電留・引上3はx=0m、車止め11400m、電留回路11180〜11400mの220m。急行側2線の車止め11860mとホーム中央10740mを区別する。回路名・分割は更新NT11配線図、距離は既存線形に整合する新提案とし、略図pxをsへ換算しない。NT11の線形・回路・18連動進路をAssetへ反映済み。

ゲーム用の番線・転轍機番号・分岐形状・回路境界をGraphへ保存した。Native IDと保存距離は[全線区間一覧](../Wiring/軌道回路区間一覧.md)、連動進路と検証結果は[NT08〜NT11反映記録](NT08_NT11Unity反映.md)を参照。追加回路の速度設定120km/h・路線最高105km/hを踏襲する。

## NT07の古谷側

旧TD-ATCのNT07に合わせ、斜め経路の途中から緩行線へ分岐する構造にした。番号と定位・反位は現在の配線図・連動図表にそろえる。下り2番線は27反位から26イへ進み、26イ定位で緩行線、26イ反位で26ロ経由の急行線へ進む。27定位は電留1線への直進。上り側は30・31イ・31ロが対応し、30定位は電留2線への直進。1・4番線から緩行へ向かう25イ／ロ・32イ／ロは別の渡り線。旧の内側±2.5m・外側±14.5m・緩行±9.5mと曲線パラメータを採用し、240mホームを直線内に収めた。

旧Transitionの3次放物線は、端点オフセットと端点の傾きを指定する`TrackEdgeCubicHermiteOffsetSegment`で保持する。古谷側7500〜7900mの線間戻しには、両端の傾きが0の既存`TrackEdgeCubicOffsetSegment`を使う。[NT07定義](NT07/NT07線形定義.md)に距離の変換・位置・経路を記す。

NT07初回の追加範囲は39 Edge・36軌道回路・24進路（場内・出発16、入換8）で、当時の全線は75 Edge・88回路・38進路だった。この段落は[初回反映記録](NT07/NT07Unity反映.md)の履歴。現行のNT08〜NT11追加後は119 Edge・154回路・56進路。NtLine.unityにはNT01・NT05・NT07・NT11連動装置を登録済み。
