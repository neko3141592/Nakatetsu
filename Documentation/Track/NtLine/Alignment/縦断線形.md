# NT線 中鉄中央〜中田の縦断線形

2026-10-27：上中田〜中田を2.2kmへ延長。中田の中心をs=16240m（営業キロ16.1km）、ホームを16120〜16360mへ900m移動し、末端を17100mへ延長した。最終の0‰区間を延ばし、高さ・勾配は維持する。

2026-10-26作成、2026-11-01更新。[中心曲線表.xlsx](中心曲線表.xlsx)の最新の水平48区間・勾配67区間を、[Geometry.json](../../../../SourceAssets/Track/Network/NakatetsuTrackGraph/Shared/Geometry.json)とUnity Graph Assetへ反映した。猿沼までの既存線形・勾配は維持する。高さはゲーム用の計画値で、地形Meshの標高を変更したものではない。距離sは中鉄中央車止めを0mとする共通Geometry距離で、各駅や区間でリセットしない。

列と計算式は既存Excelの形式を維持する。「高さ」は区間始端のレール面高さで、次の区間の高さは「現在の高さ＋開始・終了勾配の平均×区間長÷1000」。JSONは原点Y=-12m、一定勾配を`ConstantGradient`、緩和勾配を`LinearGradient`で表す。

既存の起伏を残し、全14駅のホームは水平とする。秋杉から東福岡へ5‰以下で下り、東福岡・猿沼を8mで水平に保つ。s=11880〜12300mを最大25‰で下り、羽沢台を0m、上中田を5mとする。上中田〜中田は表で指定された+1.6・−3.7・−6‰を使い、中田では1.195mで水平に戻る。中田の分岐器予定区間に入る前のs=15400mで緩和勾配を終える。全体の勾配範囲は既存部分を含めて−25〜+28‰。
