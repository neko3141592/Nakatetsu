# NT線 中鉄中央〜中田の縦断線形

2026-10-26。[中心曲線表.xlsx](中心曲線表.xlsx)の「勾配」を中田まで延長し、[Geometry.json](../../../../SourceAssets/Track/Network/NakatetsuTrackGraph/Shared/Geometry.json)へ同じ51区間を反映した。地表を一律Y=0mとするゲーム用の計画値。距離sは中鉄中央車止めを0mとする共通Geometry距離で、各駅や区間でリセットしない。

列と計算式は既存Excelの形式を維持する。「高さ」は区間始端のレール面高さで、次の区間の高さは「現在の高さ＋開始・終了勾配の平均×区間長÷1000」。JSONは原点Y=-12m、一定勾配を`ConstantGradient`、緩和勾配を`LinearGradient`で表す。

既存の起伏を残し、新桜町・東長野・山田橋のホームと重なる部分を水平に調整した。それに伴って後続区間の高さも再計算した。追加区間は秋杉から東福岡へ5‰以下で下り、東福岡・猿沼を8mで水平に保つ。s=11880〜12380mを最大20‰で下り、羽沢台〜中田は0mとした。全体の勾配範囲は既存部分を含めて−25〜+28‰。
