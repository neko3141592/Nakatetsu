番線・転轍機番号・軌道回路の区切りは検討用。番号はファイルごとに付けており、別のファイルの `下1T` は別の回路として扱う。コード上の論理IDとの対応は、別ファイルで管理する。駅間の図は上下各3回路の仮置きで、長さやATCの制動距離に基づく区切りではない。

駅間では、中鉄中央から離れる線を下り、中鉄中央へ向かう線を上りとする。軌道回路名は `下1T`・`下2T`・`下3T` と `上1T`・`上2T`・`上3T`。上下とも中鉄中央側から番号を増やし、駅間ごとに1から付ける。別ファイルで管理する論理IDは `NT01-NT02-D01`（下り）・`NT01-NT02-U01`（上り）のように駅間と線別を含め、開始・終了キロ程は別項目で保持する。

駅構内では、ホーム回路を番線番号と通常の出発方向で命名し、図の右側へ出発する番線は `RT`、左側へ出発する番線は `LT` を付ける。転轍機を含む回路は転轍機名＋`T`。シーサスの同じ斜め経路の両端を2動てこの同一番号とし、中鉄中央側をイ、反対側をロとする。

| 駅 | ホーム回路 | 転轍機 |
| --- | --- | --- |
| NT01 | 1RT・2RT・3RT | シーサス21イ／ロ・22イ／ロ、単独23 |
| NT02・NT03・NT04・NT06 | 1RT・2LT | なし |
| NT05 | 1RT・2RT・3LT・4LT | 単独21〜24 |
| NT07 | 1RT・2RT・3LT・4LT | 西シーサス21イ／ロ・22イ／ロ、単独23・24・27・30、古谷側の2動てこ25イ／ロ・26イ／ロ・31イ／ロ・32イ／ロ、電留シーサス28イ／ロ・29イ／ロ |

NT07の古谷側は旧TD-ATCの配線に合わせている。2番線根元の26イが定位なら電留線へ直進し、反位なら26ロのある下り急行線へ向かう長い斜め線へ入る。その斜め線の途中に27があり、27定位は急行線へ継続、27反位は下り緩行線へ分岐する。1番線の25イ／ロは急行線から緩行線への別の渡り線で、26イ／ロの斜め線と交差する。25／26を平行2線の通常のシーサスとして配置しない。

上り側は3番線根元の31イ／ロ、斜め線途中の30、4番線から緩行線へ渡る32イ／ロで同じ接続を鏡映している。30定位は急行線へ継続し、反位は緩行線へ分岐する。電留シーサス28イ／ロ・29イ／ロは26イ・31イの直進側のすぐ先にあり、外側急行線への合流点より手前に置く。直進側は既存の `電留1T`・`電留2T` と車止めへ続く。

NT07は全体・中鉄中央側・古谷側の3ページで転轍機名と回路名をそろえた。2動てこの両端をイ／ロの同一番号にし、回路も `25イT`・`25ロT` などに分ける。斜め線途中の単独分岐は `27T`・`30T`。27・30の定位3本線は急行線へ続く斜め側に付ける。境界は転轍機間の中央付近とし、交差点上の境界だけ少しずらしている。古谷方面の本線回路は `下急1T`・`下緩1T`・`上緩1T`・`上急1T` とする。

各駅の構成は[配線略図](../../../References/NtLineTrackDiagram.svg)を参考にしている。小泉公園の内側2線は古谷側で車止めとなり、外側2線と新しい内側2線が古谷方面へ続く。古谷側の詳細な接続は、旧TD-ATCの接続を反映したNT07配線図を使う。斜め線の交差点で別の線路へ乗り移る接続は設けない。

NT01の線形寸法は、配線図とは別の[線形図](../Alignment/NT01/NT01線形図.drawio)と[線形定義案](../Alignment/NT01/NT01線形定義.md)で管理する。
