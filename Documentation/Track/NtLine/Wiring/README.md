# NT線 配線図

[NT線軌道回路図](NT線軌道回路図.drawio)は、全11駅の配線にGeometry距離程・全154回路ID・回路境界を載せた広い編集用図。線路・回路IDは黒、回路の区切り線だけ赤とし、全線3段・各段の拡大・分岐駅のEdge別詳細の10ページで構成する。距離はNT01車止めを0mとする共通Geometry `NT01_baseline` の `s`。全線図は非等縮尺で、分岐回路の枝ごとの正確な境界はEdge別詳細に表示する。NT07—NT08延長とNT08〜NT11はGraph・ATC反映済み、参照配線図の検車区ヤードは距離・回路未定義として注記する。

中鉄中央から猿沼までの編集用draw.io図。駅構内は `Stations`、駅間は `Sections` に分け、下の順番でたどれるようにしている。NT08〜NT11とその駅間を2026-10-13にGraph・ATCへ反映し、NT11連動とNtLine.unityのController登録を追加した。[反映記録](../Alignment/NT08_NT11Unity反映.md)に実ID・保存距離・検証結果をまとめる。

[軌道回路名・区切り距離の全線図](軌道回路区間一覧.drawio)（5ページ）と[距離一覧](軌道回路区間一覧.md)に、駅間・分岐・電留・引上までをまとめた。2026-10-13の寸法改訂ではNT02・NT03・NT04・NT06の線形・駅回路と隣接駅間の回路境界をGraph・ATC Assetへ反映した。分岐器なしのNT02・NT03・NT04・NT06・NT08・NT09・NT10はホーム210m・駅回路220m、分岐器ありのNT01・NT05・NT07・NT11は240mホームを維持する。NT04は両端がすぼむホームと400mの構内線形へ変更した。NT02・NT03は駅Edgeを220m駅回路と一致させ、前後駅間Edgeを延長してGraph・ATCへ反映済み。NT08・NT09・NT10も駅Edge＝220m駅回路としてGraph・ATCへ保存済み。NT04・NT06は駅Edgeと回路を分ける現状を維持する。ホーム寸法は資料で管理し、ホームMesh・Prefab・ホームのシーン配置は未作成。NT07—NT08の回路終端7930mとNT08〜NT11の線路・回路も反映済み。

青い枠が軌道回路名、橙色の丸が転轍機番号、灰色の面がホーム。赤い斜線は距離付きの図の回路境界。各駅の番線と、隣の駅へつながる方向も表示している。転轍機付近の3本の斜線は定位側を表し、基本は直進側を定位として仮置きしている。NT11の26は3番線側の曲線を定位とする。

NT01・NT05・NT07・NT11の白い丸枠の英字は連動進路の着点符号。各ページの着点一覧を正本とし、ホーム・中間着点・本線出口・電留線・引上線の32着点を駅内で識別する。符号は別駅で共用できる。連動表のK列「着点符号」と連動Assetの `destinations`／各進路の `destinationCode` が同じ対応を保持する。着点領域の記号であり、方向別の信号位置やATC停止位置は各進路の定義で管理する。

進路IDは駅内で一意の「番号＋R/L＋必要な着点符号」。単一進路は `1R` のように着点符号を省略でき、同じ番号の `1R` と `1L` も共用できる。全体の参照は `(連動駅ID, 進路ID)` とする。2026-10-14に4駅58進路を配線図・Excel・連動／ATC Assetへ移行した。[issue #84](https://github.com/neko3141592/Nakatetsu/issues/84)に規則、駅別の着点表、旧ID→新IDの全対応を記録する。分岐器のないNT02・NT03・NT04・NT06・NT08・NT09・NT10には連動進路の着点を追加していない。

番線・転轍機番号・軌道回路の区切りは現行Graphに対応するゲーム用定義。番号はファイルごとに付けており、別のファイルの `下1T` は別の回路として扱う。コード上の論理IDとの対応は、別ファイルで管理する。駅間の図は[全線区間一覧](軌道回路区間一覧.md)の名前・距離に統一した。NT01〜NT07は保存済み回路の内部境界・IDを保ち、220m駅回路に接する両端を伸ばしてGraph・ATCへ反映した。NT03—NT04は各4回路、NT04—NT05は各1回路、NT07—NT08は各線1回路。NT08以降の駅間は各線3回路でGraph・ATCへ保存した。NT08〜NT10の駅と追加駅間はBlock制御、NT11構内はInterlocking制御。

駅間では、中鉄中央から離れる線を下り、中鉄中央へ向かう線を上りとする。軌道回路名は `下1T`・`下2T`・`下3T` と `上1T`・`上2T`・`上3T`。上下とも中鉄中央側から番号を増やし、駅間ごとに1から付ける。論理IDは保存済みGraphと同じ `NT01_NT02_D1T`（下り）・`NT01_NT02_U1T`（上り）の形式を使い、開始・終了の共通Geometry距離sを別項目で保持する。

駅構内では、ホーム回路を番線番号と通常の出発方向で命名し、図の右側へ出発する番線は `RT`、左側へ出発する番線は `LT` を付ける。転轍機を含む回路は転轍機名＋`T`。シーサスの同じ斜め経路の両端を2動てこの同一番号とし、中鉄中央側をイ、反対側をロとする。

NT08〜NT10の外側1線・4線はホームのない急行通過線で、中央2・3番線に島式ホームを置く。線順は下り急行・下り緩行・上り緩行・上り急行。NT08以降の追加駅間の回路名は各線に `下急1T〜3T`・`下緩1T〜3T`・`上緩1T〜3T`・`上急1T〜3T` を使う。NT07—NT08は各線の既存NT07 outgoing Edgeへ7900〜7930mの同横位置Constant区間を追加し、各線1回路を7930mまで延長した。7500〜7900mのCubicと各回路IDは維持する。

NT11は最新の[中田鉄道配線図](../../../References/中田鉄道配線図.drawio)にある方向別2面4線・入口の急緩シーサス・終端3線を採用し、回路名・区分はユーザー更新の[NT11配線図](Stations/NT11配線図.drawio)全体ページに合わせる。入口はNT07と同じ主線・斜線の共通距離のNative保存値10227.1279296875m（理論10227.127487m）で区切り、21／22・23／24を各4独立回路とする。25イT・25ロTの斜線境界は10990m。26はs=11160m・x=0mの中央両開き10番案とし、2・3番線を左右対称のArc＋斜直線＋逆Arcで寄せ、定位側も曲線で中央電留線へ接続する。R400mはゲーム用提案。電留Tは中央x=0mの11180〜11400mで220m。ホーム240m・入口・25・外側1/4線は維持する。区切り距離は線形に整合する提案で、略図pxをsへ換算しない。Graph・ATC・NT11連動へ反映済み。

NT08〜NT11の線番号・回路名・転轍機番号をGraphとNT11連動へ反映した。距離とホーム寸法は[線形定義一覧](../Alignment/README.md)で管理し、軌道回路の距離案は[全線区間一覧](軌道回路区間一覧.md)、Native回路Section・ATC・連動は[反映記録](../Alignment/NT08_NT11Unity反映.md)に対応する。

NT07の古谷側は旧TD-ATCの配線に合わせている。2番線根元の27が定位なら電留1線へ直進し、反位なら斜め経路の26イへ進む。途中の26イは定位で下り緩行線へ分岐し、反位で26ロのある下り急行線へ継続する。1番線の25イ／ロは急行線から緩行線への別の渡り線で、26イ／ロの斜め線と交差する。25／26を平行2線の通常のシーサスとして配置しない。

上り側は3番線根元の30、斜め線途中の31イ／ロ、4番線から緩行線へ渡る32イ／ロで同じ接続を鏡映している。30定位は電留2線へ直進し、反位で31イへ進む。31イ定位は上り緩行線へ分岐し、反位は31ロ経由の上り急行線へ継続する。電留シーサス28イ／ロ・29イ／ロは27・30の定位側のすぐ先にあり、外側急行線への合流点より手前に置く。直進側は既存の `電留1T`・`電留2T` と車止めへ続く。

NT07は全体・中鉄中央側・古谷側の3ページで転轍機名と回路名をそろえた。2動てこの両端をイ／ロの同一番号にし、回路も `25イT`・`25ロT` などに分ける。斜め線途中の単独分岐は `27T`・`30T`。27・30の定位3本線は急行線へ続く斜め側に付ける。境界は転轍機間の中央付近とし、交差点上の境界だけ少しずらしている。古谷方面の本線回路は `下急1T`・`下緩1T`・`上緩1T`・`上急1T` とする。

各駅の構成は[配線略図](../../../References/NtLineTrackDiagram.svg)を参考にしている。小泉公園の内側2線は古谷側で車止めとなり、外側2線と新しい内側2線が古谷方面へ続く。古谷側の詳細な接続は、旧TD-ATCの接続を反映したNT07配線図を使う。斜め線の交差点で別の線路へ乗り移る接続は設けない。

NT01の線形寸法は、配線図とは別の[線形図](../Alignment/NT01/NT01線形図.drawio)と[線形定義案](../Alignment/NT01/NT01線形定義.md)で管理する。
