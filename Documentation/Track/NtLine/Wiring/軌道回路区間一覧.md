# NT線 軌道回路名・区切り距離一覧

2026-10-13更新。[編集用全線図](軌道回路区間一覧.drawio)は全線一覧とNT01・NT05・NT07・NT11の回路詳細5ページ。[距離データ](軌道回路区間一覧.json)は保存・再読込済みGraphのNative 119 Edge・154回路・245 Sectionと一致する。NT08〜NT11とNT07古谷方7930mまでの延長をGraph・ATCへ反映し、NT11連動AssetとNtLine.sceneのController登録を追加した。[反映記録](../Alignment/NT08_NT11Unity反映.md)に実ID・変更内容・検証結果をまとめる。ホーム210m／240mは資料寸法で、Graphにホーム項目はなく、ホームMesh・Prefab・ホームのシーン配置は未作成。

距離はNT01車止めを0mとする共通Geometry `NT01_baseline`の連続距離`s`（m）。各線路の走行実距離、営業キロ、Unityの全線Z座標とは区別する。区間は隣接する境界を共有し、両端を二重に占有する意味にはしない。一覧図は小数3桁、Native Edge詳細表は小数6桁まで、JSONは保存済み単精度値をそのまま保持する。線形図の理論設計値とは丸め差を区別する。

## 分岐・引上・ホーム回路の詳細

1回路に複数のEdge区間が含まれる場合は、同じ回路IDで複数行を表示する。開始・終了の最小／最大から単一の回路長を求めない。分岐の各枝の長さは別々に扱う。

NT01・NT05・NT07は保存済みAssetの距離・IDを転記した。配線図のイ／ロは論理IDのA／Bに対応する（例：21イT＝21AT）。NT07の電留線は7280mで終わり、古谷方の4線とは別の終端。

NT11の回路名・分割は、2026-10-13にユーザーが更新した[NT11配線図](Stations/NT11配線図.drawio)の全体ページを採用した。距離は既存の線形に整合する新提案で、略図のpxを共通距離sへ換算しない。ホーム240m・入口・25・外側1/4線は維持し、26を中央x=0mの10番対称Arc両開きへ改訂し、Assetへ反映した。

入口はNT07と同じく、主線・斜線の両方をNative保存値`s=10227.1279296875m`（理論10227.127487m）で区切る。下り21／22は21イT・22イT・21ロT・22ロTの4独立回路。1番線直進は21イT→22ロT、2番線直進は22イT→21ロT。斜線21は21イT→21ロT、斜線22は22イT→22ロT。上り23／24も同じ対応で、3番線直進は23イT→24ロT、4番線直進は24イT→23ロT、各斜線は同番号のイT→ロTとなる。2本の斜線の交差は非接続。

終端は25イT・25ロTを別回路とし、渡り線25を`s=10990m`で二分する。26Tは2番線の対称Arc連絡部11020.012695〜11160mと3番線10890〜11180mを含み、合流26の3枝を覆う。電留Tは中央x=0mの3番線11180〜11400mの220mで、200m編成の車体11190〜11390mを収める。1引T・4引Tと3つの車止めは維持する。

ホーム回路は10590〜10890mの300mとして240mホームの前後30mを覆う。2番線に独立した尾端・車止めは設けない。

回路区切りはNative Graph保存値。NT08〜NT10・駅間はBlock制御、NT11はInterlocking制御。追加回路速度120km/h・路線最高105km/hは既存設定を踏襲する。
