# NT線の実装範囲と駅一覧

## 確定範囲

今回の実装は**中鉄中央（NT01）から猿沼（NT11）まで、両端を含む11駅・営業キロ10.6km**とする。羽沢台（NT12）〜真鍋（NT28）は今回の実装対象外。

根拠は本人作成の`Documentation/References/Stations.xlsx`と「今回の実装では猿沼駅まで」という指定。確認日は2026-09-21。従来の実装計画の「約10km・約10駅」をこの範囲に置き換える。駅名・キロ程・種別別停車駅の正本はExcelとし、本書は確認時点の実装範囲を記録する。

## 種別と速度

出典：`列車種別!B2:G13`、`B32:G32`。停車指定はExcelに保存された論理値を読む。

| 種別 | 営業最高速度（km/h） | NT01〜NT11内の停車駅 |
| --- | ---: | --- |
| 各停 | 110 | 全11駅 |
| 急行 | 110 | 中鉄中央、猿沼 |
| 準急 | 110 | 中鉄中央、東長野、小泉公園、猿沼 |
| 通勤急行 | 110 | 中鉄中央、小泉公園、古谷、秋杉、東福岡、猿沼 |
| 特急 | 120 | 中鉄中央 |

本人指定の営業最高速度120km/hは全体の上限とし、種別別上限は上表に従う。各停を120km/h運転にしない。区間・分岐・ATCの制限は別途適用する。

5種別すべてを今回実装する決定ではない。初期版は既存計画の各停中心を維持し、採用種別とダイヤは運行設計で決める。特急の猿沼停車はExcelではFALSE。特急を今回の区間に設定する場合は終端での扱いを別途決める。

## 確認結果と出典の所在

- NT01〜NT28のIDは重複なし。2シート間で駅名・キロ程が一致。
- 保存済みの駅間距離は隣接駅のキロ程差と一致（比較許容差`1e-9 km`）。
- `列車種別!C3:G30`の140セルはすべて論理値。文字列のTRUE/FALSEではない。
- 保存されたセル値に数式エラーなし。ブックの編集・再計算・上書きは行っていない。

元プロジェクト側で確認した[Stations.xlsx](../References/Stations.xlsx)を、内容を変更せずこのブランチへ収録した。駅一覧の正本として以後このリポジトリで管理する。

## 配線確定時の残件

- 各駅の番線、ホーム形状・有効長、方向別停止位置。
- 複線区間と分岐配置、閉塞境界、進路表。
- 猿沼での終端運用と、200m編成の収容・生成退出に必要な線路余裕。営業キロ10.6kmと線路の必要延長は区別する。
- 新規線形の曲線・勾配・分岐間隔と、確定した駅間距離の整合。
