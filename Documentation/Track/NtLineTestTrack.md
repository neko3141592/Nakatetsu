## 線形・ホーム

共通Geometryは `nt-line`、水平直線・勾配0‰、原点 `(0, 0, -180)`。本線経由の全長は2,520m、待避線経由は約2,521.331m。転轍機21は1,020m、22は1,500m。両方とも定位が本線、反位が待避線。

| Edge ID | Geometry距離 | 内容 |
| --- | --- | --- |
| `nt-approach` | 0〜1,020m | 左側自動閉そくと21T共通部 |
| `nt-main` | 1,020〜1,500m | 21・22間の直線本線 |
| `nt-loop` | 1,020〜1,500m | 待避線、実距離約481.331m |
| `nt-exit` | 1,500〜2,520m | 22T共通部と右側自動閉そく |

待避線は `TrackEdgeArcOffsetSegment` と一定オフセットで構成する。円弧の接続点では位置と接線を合わせる。曲率の緩和は設けない。

Sceneの `Track/Graph/IslandPlatform_240m` が簡易ホーム。Geometry距離1,140〜1,380m、長さ240m・幅6.6m・高さ1.1m。線路中心間隔は10m、ホーム中心のワールド座標は `(5, 0.55, 1080)`。ホーム両端からホーム軌道回路境界までは各20m。

距離表は直線の端点と境界、円弧はGeometry距離0.5m刻みで保存し、円弧長からEdge実距離を算出。線形を編集したら既存のGraph Inspectorの `Compile Distance Maps` で再生成できる。

## 軌道回路

21T・22Tは共通部と両枝の3区間を持つY字型。どの枝の占有も同じ回路に反映される。

| 回路ID | EdgeとGeometry距離 |
| --- | --- |
| `20T` | `nt-approach`: 0〜1,000m（自動閉そく） |
| `21T` | `nt-approach`: 1,000〜1,020m、`nt-main` / `nt-loop`: 1,020〜1,120m |
| `1RT` | `nt-loop`: 1,120〜1,400m（待避線ホーム、280m） |
| `2RT` | `nt-main`: 1,120〜1,400m（本線ホーム、280m） |
| `22T` | `nt-main` / `nt-loop`: 1,400〜1,500m、`nt-exit`: 1,500〜1,520m |
| `23T` | `nt-exit`: 1,520〜2,520m（自動閉そく） |

轍査鎖錠は `21 → 21T`、`22 → 22T`。

## 連動進路

`NtLineInterlocking.asset` の進路IDは発点・着点をそのまま使用する。

| 進路ID | 種別 | 転轍機位置 | 進路鎖錠回路 | 接近鎖錠の照査回路 |
| --- | --- | --- | --- | --- |
| `21T-1RT` | 場内・待避線 | 21反位 | 21T、1RT | 20T |
| `21T-2RT` | 場内・本線 | 21定位 | 21T、2RT | 20T |
| `1RT-22T` | 出発・待避線 | 22反位 | 22T | 1RT |
| `2RT-22T` | 出発・本線 | 22定位 | 22T | 2RT |

場内進路同士、出発進路同士を競合とする。場内と出発は別の転轍機を使用し、同時に要求できる。出発進路の鎖錠対象に発点ホームを含めないため、ホーム占有中でも出発要求が可能。接近鎖錠は既存仕様どおり、取消時に照査回路が占有なら60秒の時素を掛ける。

## 自動閉そく・ATC入力

`NtLineAtcGraphSource.asset` は既存の `TrackAtcGraphCompileDefinition` を保存する入力Asset。連動進路は上記進路IDと順序付きの物理区間で指定する。制御方式は20T・23Tが `Block`、21T・22T・1RT・2RTが `Interlocking`。生成済みの `NtLineAtcGraph.asset` も同じ区分にそろえる。この試験線に `Yard` 区間はない。

- 20T・23Tは連動進路に含めず、物理Edgeの `travelDirection = AtoB` を使用する。
- 場内進路は21T共通部から指定枝のホーム回路末端まで。出発進路は発点ホーム回路から22T共通部末端まで。
- 試験用の基本速度は80km/h、待避線の分岐・合流円弧区間は25km/h。制限は生成元のGeometry距離区間で保存する。
- 勾配サンプル間隔は10m。全区間0‰。

`NtLineAtcGraph.asset` にGraph、ATC入力、Interlockingの参照を割り当て済み。Inspectorの `Compile ATC Graph` で生成結果を同じAssetへ保存できる。追加時点では未コンパイル。操作方法は [ATC Graphのコンパイル](TrackAtcGraphCompilation.md) を参照。ATCの実行時制御への接続は別途必要。
