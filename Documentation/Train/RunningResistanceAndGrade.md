# 走行抵抗と勾配による力

編成前方向を正とし、各車の力を編成物理へ合計する。

## 走行抵抗

各車の `CarDefinitionAsset` に Davis 型の係数を設定する。速度 `v` の単位は m/s。

```text
R(|v|) = A + B |v| + C |v|²
走行中の力 = -sign(v) R(|v|)
```

`A` は N、`B` は N·s/m、`C` は N·s²/m²。既存の Series1000 と Series10000 の車両定義には、調整前の仮値として各車 `A=300`、`B=8`、`C=0.5` を設定した。

速度がゼロのときは、定数項 `A` が駆動力・勾配による力・その他の外力を打ち消す範囲だけ働く。走行抵抗だけで列車が発進することはない。

## 勾配による力

車両中心の線路サンプルの `GradientPermille` と、その時点の乗客を含む車両質量から求める。正の勾配は編成前方向への上り。

```text
s = GradientPermille / 1000
勾配による力 = -質量 × 9.80665 × s / sqrt(1 + s²)
```

勾配による力は速度ゼロでも働き、走行抵抗とブレーキの保持力を超えれば坂を下る。線路サンプルを取得できない車両の勾配による力は、そのステップではゼロとする。

`externalForceN` は他の外力用に残し、走行抵抗・勾配による力とは別に集計する。
