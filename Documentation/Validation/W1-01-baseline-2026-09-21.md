初回の失敗は`BrakeControlDeviceTests.TargetForceIsConvertedToCommonCylinderPressure`。期待250 kPaに対し実測250.000015 kPaで、floatの完全一致比較が失敗した。力・面積・効率からの計算式は変更せず、同じファイルの別ケースと同じ`Within(0.001f)`を圧力の期待値に追加した。0.001 kPaは1 Paで、変換単位や倍率の誤りを隠す大きさではない。

初回インポート中、ShaderGraphパッケージの`GUID`型でCS0246が2件出た。その直後にUnity API UpdaterがPackageCacheを更新し、再コンパイルしてテスト実行まで到達した。プロジェクト側のパッケージソース修正は行っていない。空Assemblyとパッケージ間の`System.Runtime.CompilerServices.Unsafe.dll`重複の警告も初回ログにある。最終結果と初回の途中エラーを混同しない。

初回PlayModeは`-nographics`によりURPのRenderTexture生成で失敗した。エラーログを無視する変更は加えず、`-nographics`を外してApple M5のMetal描画を有効にした再実行で成功した。

## 再実行

プロジェクトルートから、同じworktreeのUnity Editorを閉じた状態で実行する。`-quit`はTest Runnerの終了を待たなくなるため付けない。PlayModeには`-nographics`を付けない。

```sh
mkdir -p Logs/W1-01
UNITY_EDITOR=/Applications/Unity/Hub/Editor/6000.4.0f1/Unity.app/Contents/MacOS/Unity
"$UNITY_EDITOR" -batchmode -nographics -projectPath "$PWD" \
  -runTests -testPlatform EditMode \
  -testResults Logs/W1-01/editmode-verified-results.xml \
  -logFile Logs/W1-01/editmode-verified.log
"$UNITY_EDITOR" -batchmode -projectPath "$PWD" \
  -runTests -testPlatform PlayMode \
  -testFilter Nakatetsu.Train.Debugging.Tests.TrainBaselineTests \
  -testResults Logs/W1-01/playmode-metal-results.xml \
  -logFile Logs/W1-01/playmode-metal.log
```

集計結果は[W1-01-results.json](W1-01-results.json)。詳細ログ・NUnit XMLはGit管理外の`Logs/W1-01/`に保存した。初回は`editmode.log`/`editmode-results.xml`、描画無効時の失敗は`playmode.log`/`playmode-results.xml`。Editorが生成したフォントキャッシュ、IDE設定、パッケージ由来のdefine変更は作業差分に含めない。
