# W1-03 線路上移動の実装結果

完了日：2026-09-24。W1-03は今回合意した実装範囲で完了。W1全体の合格判定とW1-05の検証は別に行う。

## 実装結果

- `TrackGraph`からGeometry・Edge・Node・ConnectionをIDで参照できる。Geometryの直線・円弧・緩和曲線、縦断、Edgeの一定・線形・円弧オフセットを評価できる。
- Edgeの距離表から実距離とGeometry距離を対応付け、`TrackEdgeDefinition.LengthM`で実長を取得できる。
- `TrainTrackPositionController`が先頭車中心のEdge ID・Node Aからの実距離・編成前方向を保持する。Physicsが出した符号付き移動距離を受け取り、Edge内移動、接続状態に従うEdge跨ぎ、終端での停止を処理する。
- 編成が通ったEdgeの列を保持し、車両番号と車体中心からのオフセットで`TryGetTrackSample`を呼ぶと、各車両の線路上の位置・姿勢を取得できる。台車表示は前後のサンプルから車体姿勢を決める。
- デバッグ用の初期位置コンポーネントが、GraphとConnectionの初期化後に`SetTrackPosition`を呼ぶ。位置設定はPresentationの生成処理から分離した。
- `NtLineGraph`に全長1000 mの試験線を用意した。最初の100 mが直線、次の200 mが半径220 mの円弧、残り700 mが直線。Edge IDは`preview-straight`を維持した。

## 今回の範囲と確認状況

- 当初の[移動結果の契約](../Architecture/TrackMovement.md)にある実移動距離・未消費距離・終了理由のDTOは、今回の相談で省略すると決めた。終端では基準点を境界で止める。
- ユーザーがUnity上で列車の走行とEdge跨ぎを確認した。今回の完了記録に伴うテストの追加・実行はしていない。
- 境界、後退、終端、大きな移動量の体系的な確認と独立ビルドはW1-05で行う。運転入力・画面表示・車体Prefabまで含む統合確認はW1-04の対象とする。
- スナップショットからの位置・経路復元は後続作業。現在の初期位置コンポーネントは試験シーン用である。

基盤段階の検証は[中間実装の記録](W1-03-track-foundation-2026-09-22.md)を参照。
