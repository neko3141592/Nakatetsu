# Nakatetsu 背景制作コア機能の3日間実装計画

3日目の完了時点で、Unityの確認用シーンに短い地下区間を組み、GuideLineからの面生成とPrefab配置を同じEdge上で使える状態にする。作業時間は1日4〜5時間、合計12〜15時間を目安とする。

## 実装範囲

| 機能 | Inspectorで指定する内容 | 確認用の例 |
| --- | --- | --- |
| 連続面 | 2本のGuideLine、開始・終了距離、サンプリング間隔、マテリアル、面の向き | トンネルの壁・天井 |
| 頂点指定面 | 頂点ごとの `GuideLine ID＋距離`、頂点の並び順、マテリアル、面の向き | 線路を横切る面、斜めの端面、開口部の周囲 |
| Prefabの単体配置 | GuideLine、配置距離、Prefab、回転補正、勾配への追従設定 | 案内標 |
| Prefabの繰り返し配置 | 単体配置と同じ姿勢設定に加え、開始・終了距離、配置間隔 | 照明や柱 |

## EdgeとGuideLineの取り決め

- GuideLineはEdge単位で定義する。1本のEdgeに複数のGuideLineを登録できる。初版の各GuideLineはEdgeからの一定の横・高さオフセットで表す。
- 距離はすべてNode AからのEdge実距離［m］とする。連続面の両端点、横断面の頂点、Prefabの繰り返し間隔に同じ距離基準を使う。
- 位置評価には既存の `TrackEdgeCalculator.TryEvaluate` を使う。横・高さのオフセットは、取得した姿勢のローカル右・上方向に加える。これにより、同じEdge距離で評価した頂点は共通の断面上に並ぶ。
- PrefabはGuideLineの接線を前方向とする。鉛直配置では接線を水平面へ投影し、回転補正を適用する。
- 生成コードは沿線生成を担当する `World` 配下に置く。`Nakatetsu.World` から `Nakatetsu.Track.Graph` と `Nakatetsu.Track.Shared` を参照する。Inspectorで編集する定義、位置・メッシュの計算、Unityオブジェクトへの反映を分ける。

## 1日目 — GuideLineとPrefabの単体配置

1. `Assets/Scenes/Sandbox` に確認用シーンを用意する。距離表を生成済みのGraph Assetを接続し、Play ModeでGraphの初期化後に背景を生成する。
2. Edge参照、GuideLineのIDとオフセット、単体配置の設定をInspectorから入力できるようにする。
3. 指定距離でGuideLineの位置と接線を評価する。Edge端では区間内側の点を使って接線を求める。
4. 評価した位置と向きでPrefabを1個置き、回転補正と勾配追従を反映する。

**完了条件**　直線・曲線・勾配で配置位置を確認できる。同じ勾配区間で、勾配に沿う配置と鉛直に立つ配置の両方を確認できる。

## 2日目 — 連続面と頂点指定面

1. 連続面は、2本のGuideLineを共通の距離でサンプリングし、隣接するサンプルを三角形でつなぐ。終了距離が間隔の倍数に合わない場合も終点を含める。
2. 頂点指定面は、頂点の指定順に境界を作り、三角形に分割する。初版は平面上の凸多角形を対象とする。頂点間は直線で結び、開口部の周囲は左右と上部を別々の面で構成する。
3. 両方式にマテリアル、UV、表裏を反映する。連続面は幅方向とEdge距離方向、頂点指定面は面内の座標をUVの基準にする。

**完了条件**　曲線に沿う壁を表示できる。同じ距離の頂点を結ぶ横断面と、左右の頂点の距離を変えた斜めの面を作れる。運転席側から意図した面が表示される。

## 3日目 — 繰り返し配置と統合確認

1. 単体配置と同じ位置・姿勢評価を使い、開始地点から指定間隔でPrefabを並べる。終了地点を超える配置は行わない。
2. 確認用シーンで、壁と天井を連続面、開口部の周囲を頂点指定面、照明を繰り返し配置、案内標を単体配置で組み立てる。
3. Play Modeで生成・再生成し、位置と向き、配置個数、面の見え方を確認する。再生成時は前回の生成物を置き換える。

**完了条件**　4機能を同じシーンで動かせる。再生成でメッシュやPrefabが重複しない。存在しないID、Edgeの範囲外の距離、ゼロ以下の間隔、面を作れない頂点列を検出し、該当する定義を特定できる。

## 3日後に扱う項目

本番の地下区間への展開、JSON入出力、専用編集UI、Edgeをまたぐ面の接続、凹多角形や穴を直接扱う面生成は後続工程に回す。
